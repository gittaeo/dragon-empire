# 에이전트 협업 보드 (Claude Code ↔ Codex)

> **규칙** — 두 에이전트 모두 작업을 *시작하기 전*과 *끝낸 직후* 이 파일을 읽고 갱신한다.
> 1. 시작: `git pull` → 이 보드 확인 → "진행 중"에 내 작업·담당 파일을 적고 커밋·push (잠금 선언).
> 2. 다른 에이전트가 잠근 파일은 수정하지 않는다. 필요하면 "질문함"에 요청을 남긴다.
> 3. 방향이 다르면(외형·규칙·스토리) 임의로 덮어쓰지 말고 "방향 차이"에 적어 사용자 결정을 받는다.
> 4. 끝: "진행 중"에서 지우고, 결과는 HANDOFF.md에, 상대에게 넘길 일은 "질문함"에 남긴다.
> 5. 실시간 대화: Claude → Codex는 `scripts/ask-codex.sh`(새 Codex) 또는 사용자 승인 시 Codex 데스크톱 스레드에 메시지. Codex → Claude는 이 보드의 질문함(Claude는 매 단계 시작 시 확인).

## 확정 (사용자, Codex 스레드 2026-11-20)
- 주인공 인간형 = **여성 폴리모프**, 인간형에서도 **뿔·꼬리 항상 노출**. Codex가 에셋 제작, Claude가 게임 연결(ground.js의 `human = person(...)` 교체).
- **영구 성장**: 용의 성장·세계 진행은 영구 저장, 처음부터 하려면 **새 저장 슬롯**(기존 용 보존). 성체까지 **3~4일**(퀘스트·탐험·진화 병행) — 구체 수치·일정은 기획 가설(미확정).

## 방향 차이 · 사용자 결정 필요
- **(최우선) 방향 전환 제안 「풍향탑의 세 밤」** — docs/PIVOT_THREE_NIGHTS.md. 사용자가 1인 1달 출시를 위해 범위 축소 요청 → Claude·Codex 토론 결과 둘 다 B안(낮=인간형 준비, 밤=용 방어, 3밤, 루세르나) 추천. 결정 전까지 3단계 임무(MISSION_03) 구현 보류.
- **성장 속도**: P0(growth.js) + 2단계 임무·웜 회피 시험(quests.js) 구현. 남은 것 → 3단계(웜→엠페러) 임무·최종 시험, 발견지 추가, 세션 보상 재설계, 사람 플레이 시간 측정.
- **슬롯 간 용의 결정 공유**: 현재 공용(기존 키 유지). 슬롯별로 나눌지 미정.
- **스토리 추천안**(Codex·스토리 에이전트): '마지막으로 알려진 알', 엠페러 이후 계속 비행, 숨결 가둔 등불 해방·마을 등불은 자유 숨결로 수리, 연맹은 회색 동기 — 사용자 미확정.
- **지상 임시 제약** 확인 대기: HANDOFF 2026-11-20 '지상 첫 시제품' 항목.
