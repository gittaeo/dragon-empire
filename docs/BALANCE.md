## 3. 진화 분기
| 시점 | 내용 |
|---|---|
| Lv10 도달 | 게임 일시정지, 화염/폭풍 선택 카드 2장 (선택 전 15초 무적 유지). 이 선택이 판 끝까지 고정 |

| 보스 처치 → Lv30 | 4단계 '드래곤 엠페러'. 궁극기 1회 자동 충전 → 30초 '황제의 비행' 후 결과 화면 |

혈통 기본 성격: **화염** = 기본 피해 +15%, 화상 지속 피해 · **폭풍** = 이동속도 +20%, BOOST/DODGE 쿨 −20%, 최대 HP +10%(현재 구현의 HP+25 방향 유지).
1단계 외형은 보유 드래곤의 기본형(첫 버전: 불씨 해츨링). 돌풍 해츨링은 장기 확장(수집)에서 '폭풍 계열 알'로 획득.

## 5. 궁극기 게이지 (공통)
- 처치 XP의 1% + 받은 피해의 0.5%만큼 충전. 1–3단계에선 사용 불가(4단계 전용, SKILLS.md 기준).
- 엠페러 진화 순간 100% 자동 충전. 보스전 광고 보상(§8 ③)으로만 예외적으로 미리 사용 가능.

## 6. 결과 화면 & 재화 공식 (용의 결정)
```
용의 결정 = floor( (20 + 도달Lv×4 + 처치점수 + 진화보너스 + 보스보너스)
                   × 결과배율 × (1 + 영구 '용의 탐욕' 보너스) )
  처치점수   = Σ 적별 처치 점수 (§2 표)
  진화보너스 = (도달 단계 − 1) × 40          // 최대 120
  보스보너스 = 등불 파괴 수 × 10 + 처치 시 150
  결과배율   = 클리어 1.0 / 실패 0.5
```
| 예시 | 계산 | 획득 |
|---|---|---|
| 클리어 (Lv30, 처치점수 ~215) | (20+120+215+120+230) × 1.0 | 약 705 |
| Lv15에서 사망 | (20+60+70+40+0) × 0.5 | 약 95 |
| Lv5에서 사망 | (20+20+5+0+0) × 0.5 | 약 22 |

결과 화면 표시 항목: 선택 혈통(경로 아이콘 4개), 도달 레벨·단계, 플레이 시간, 처치 수(적 종류별), 최대 연속 처치, 보스 처치 여부/시간, 획득 용의 결정(광고 2배 버튼), 신기록 배지.

## 7. 영구 성장 (용의 결정 소비, 판 시작 시 적용)
비용: `100 × 1.4^(n−1)` (n = 다음 레벨), 각 최대 10레벨. 한 항목 만렙 총 약 6,970.
| 항목 | 효과/레벨 | 최대 |
|---|---|---|
| 비늘 경화 | 최대 HP +4% | +40% |
| 숨결 화력 | 모든 피해 +3% | +30% |
| 날개 근력 | 이동속도 +2%, BOOST 쿨 −3% | +20% / −30% |
| 고대의 기억 | 획득 XP +3% (한 판 단축) | +30% |
| 용의 탐욕 | 용의 결정 획득 +4% | +40% |

> '고대의 기억' 만렙 시 한 판 약 8분 → 하한(8분) 보호를 위해 XP 보너스 합계 상한 +35%.

**확장 대비(구현 안 함):** 드래곤 수집 시 중복 획득 → '비늘 조각'(드래곤별 강화 재화). 드래곤별 강화는 위 5항목과 별개로 해당 드래곤에만 적용. 뽑기·결제는 재화 테이블에 `source` 필드만 남겨 두고 미구현.
