# 엠페러 모드 · 스킬 진화 설계 v0.1 (2026-11-20, 사용자 승인 방향)
> 사용자 요청: "드래곤 엠페러 상태로도 활공하고 적을 죽일 수 있어야 한다. 진화했으니 스킬도 진화하고 뽕맛이 있어야 한다. 날아다니는 MMORPG처럼."
> 게임 디자이너 에이전트 초안 기반. 수치는 초기값이며 플레이테스트로 조정. M1은 구현됨, M2·M3는 미구현.

## 흐름
- Lv30 도달 → **대관식 4초**(처음 0.6초 0.3배 슬로모션, 카메라 반 바퀴 회전 후 복귀, 금빛 폭발 3회, 반경 90m 일반 적 소멸, HP 100%·무적 3초·ULT 100%). 게임은 끝나지 않는다.
- **황제의 하늘**: 계속 비행·사냥. Lv30 이후 경험치는 **황제 위계** 바(필요량 1200+300·rank)에 쌓이고, 위계마다 피해 +2%(최대 20위계), HP 20% 회복, 배너.
- **종료**: Lv30 이후 HUD/일시정지의 **'귀환 · 보상 받기'**. 엠페러 상태 사망도 귀환 처리(보상 100%). Lv30 전 사망은 보상 ×0.5.
- 보상: `floor((20 + Lv×4 + floor(처치×1.5) + (단계−1)×40 + min(위계,10)×15 + 보스150) × (Lv30?1:0.5))`, 위계 10 초과 구간의 처치·위계 보상은 절반.
