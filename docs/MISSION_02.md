# 미션 02 — 끊긴 등불길

> **제안 · 사용자 확인 대기.** 임무, 인물, 대사, XP와 시험 수치는 플레이테스트 전 초안이다.
> 주인공은 하늘에서 용으로 날고, 땅에서는 뿔과 꼬리가 드러나는 여성 인간형으로 폴리모프한다.

## 2일차 목표

첫 임무와 비행 시험을 마친 드레이크(Lv10)가 끊긴 항로를 조사하고 웜(Lv20)으로 진화한다.
2일차 플레이 목표는 50~60분, 누적 목표는 95~120분이다. 실제 날짜로 입장을 제한하지 않는다.
세라가 풍향탑의 이상 점멸을 발견한다. 공터에 피신한 항로지기 **이안**이 항로 기록을 확인하고 안전한 시험을 돕는다.
이안은 신규 인물 제안이다. 점멸을 누가 일으켰는지는 이 구간에서 밝히지 않는다.

| 내용 | 2일차 목표 시간 | 퀘스트 XP | 탐험 XP | 제작 XP | 전투 XP |
|---|---:|---:|---:|---:|---:|
| 안개 속 신호 | 14~17분 | 140 | 100 | 60 | 100 |
| 둘로 갈린 불빛 | 16~19분 | 160 | 100 | 60 | 100 |

| 합계 | 50~60분 | 480 (40%) | 300 (25%) | 120 (10%) | 300 (25%) |

- 표의 반경은 발견용이다. 착륙은 기존 `ZONE`의 수평 중심과 220 m 반경, 지형·충돌 판정을 그대로 쓴다.
- 지상은 세 임무 모두 풍향탑 공터 한 곳에서 진행한다. 기존 착륙 → 폴리모프 → 채집 → 제작 → 수리 → 재이륙 흐름을 분산해 쓴다.
- 각 섬과 감시탑은 용형의 공중 접근으로 처리한다. 체크포인트는 지형과 장애물 바깥에 배치하고, 중심 좌표는 지도 안내에 사용한다.
- 공터의 기존 세라·작업대·풍향탑 상호작용과 자원 메시를 재사용한다. 이안 한 명과 임무용 채집물만 추가한다.

## 1. 안개 속 신호

1. **공터 · 지상** — 착륙 후 여성 인간형으로 변신하고 세라에게 수리된 풍향탑의 점멸 이야기를 듣는다.
2. **공터 · 지상** — 채집물에서 가지 1·돌 1·숨결 파편 1을 확보하고 기존 작업대에서 신호 렌즈를 제작한다.
3. **골짜기 아치 → 안개 섬 · 하늘** — 용으로 복귀해 이륙한다. 아치 곁 바깥 표식을 지나 안개 섬에서 점멸 표식 두 개를 순서대로 스친다.
4. **안개 섬 · 하늘** — 외곽의 순찰을 정리하고 조사 완료를 기록한다. 표식 두 개와 순찰 정리가 모두 충족되면 탐험 XP가 지급된다.
5. **공터 · 지상** — 착륙해 폴리모프한 뒤 이안에게 신호를 보고한다. 이안은 신호 간격이 옛 송신표와 다르다는 사실을 확인한다.
6. 보상은 `quest: {m2_fog_report: 140}`, `craft: {m2_signal_lens: 60}`, `survey: {m2_fog_route: 100}`이다. 순찰의 목표 전투 XP는 100이다.

## 2. 둘로 갈린 불빛

1. **공터 · 지상** — 이안의 송신표를 받아 서쪽 감시탑을 경유할 항로를 확인한다.
2. **서쪽 감시탑 → 등불 사슬 섬 · 하늘** — 감시탑 바깥에서 이안이 알려 준 첫 점멸을 확인한다. 사슬 섬에서 두 번째 점멸을 읽는다.
3. **등불 사슬 섬 · 하늘** — 낮은 접근로에 한 차례 예고 사격이 지나간다. 바닥 띠와 점멸음이 뜨면 옆 또는 위로 빠지고, 외곽 경비를 정리한다. 두 신호와 전투 완료를 기록하면 탐험 XP를 받는다.
4. **공터 · 지상** — 착륙·폴리모프 후 가지 1·돌 2를 모아 작업대에서 신호 렌즈를 개량한다. 이안에게 두 신호의 순서를 보고한다.
5. 보상은 `quest: {m2_chain_report: 160}`, `craft: {m2_wind_lens: 60}`, `survey: {m2_chain_route: 100}`이다. 경비의 목표 전투 XP는 100이다.

## 3. 바람길을 다시 잇다

1. **공터 · 지상** — 세라에게 개량 렌즈를 보여 준다. 이안의 기록과 대조할 쌍둥이 섬 항로가 표시된다.
2. **쌍둥이 섬 · 하늘** — 두 섬 사이의 안전 간격에서 각 섬 바깥 표식을 차례로 확인한다. 마지막 호위대를 정리하면 항로 조사가 확정된다.
3. **골짜기 아치 → 공터 · 하늘** — 아치 바깥의 귀환 표식을 지나 공터에 착륙한다.
4. **공터 · 지상** — 여성 인간형으로 변신해 수리된 풍향탑에 개량 렌즈를 끼워 신호를 맞춘다. 이안과 송신표를 대조해 보고를 마치면 회피 시험 안내가 열린다.
5. 보상은 `quest: {m2_twin_report: 180}`, `survey: {m2_twin_route: 100}`이다. 호위대의 목표 전투 XP는 100이다.

## 경로 안내와 복구

| 시점 | 기본 안내 | 놓쳤을 때 |
|---|---|---|
| 공터에서 이륙 | 진행 중인 항로의 첫 표식과 거리 표시 | 공터에 다시 내려도 단계 유지 |
| 조사 표식 통과 | 다음 표식만 강조하고 완료 수 표시 | 먼저 지나친 표식을 다시 안내 |
| 마지막 무리 정리 | 조사 완료 배너와 귀환 표식 표시 | 남은 적이 있으면 무리 방향 표시 |
| 공터 착륙 | 변신 입력 표시 | 용으로 재이륙해도 보고 상태 유지 |
| 인간형 보고 | 현재 단계의 NPC 상호작용 표시 | 대화를 닫으면 다시 말을 걸어 마무리 |
| 시험 입구 | 준비 입력과 남은 XP 조건 표시 | 항로 진행은 유지하고 공터로 돌아갈 수 있음 |

- 표식은 지형 표면을 통과할 필요가 없는 접근점에 둔다. 양방향에서 지나갈 수 있고, 먼저 발견한 랜드마크도 순서에 맞춰 조사할 수 있다.
- 무리는 한 번에 한 소그룹씩 활성화한다. 조사 반경을 이탈한 동안에는 새 무리 진입을 유예한다.
- 안개 섬에서는 짧은 점멸 간격을 읽고, 사슬 섬에서는 같은 신호가 탄막 경고로 쓰임을 배운다. 쌍둥이 섬에서 얻은 기록으로 풍향탑 송신 순서를 맞춘다.
- 보고 또는 설치를 완료하면 다음 단계와 함께 보상 마커를 기록한다. 대사 스킵과 재접속 시에도 확정된 단계부터 재개한다.

## 제작과 보상 연결

| 제작품 | 레시피 | 사용처 |
|---|---|---|
| 신호 렌즈 `m2_signal_lens` | `{branch: 1, stone: 1, shard: 1}` | 작업대에서 제작. 하늘에서 조사 표식이 보인다. |
| 바람맞춤 렌즈 `m2_wind_lens` | `{branch: 1, stone: 2, m2_signal_lens: 1}` | 작업대에서 개량. 풍향탑에 설치해 최종 보고를 마친다. |

- 공터에 임무 전용 자원 묶음을 단계별로 제공한다. 임무 외 소비로 재료가 모자라면 세라가 부족분을 보충한다. 제작·설치 상태, 소비, 보상 마커는 같은 슬롯 저장에 반영한다.
- 퀘스트·제작은 기존 `REWARDS.quest`·`REWARDS.craft`에 키를 더한다. 기존 `REWARDS.discovery`는 수치형이므로 조사 보상 표인 `REWARDS.survey`를 추가하고 지급 원천은 `discovery`로 기록한다.
- 조사 세 건은 `disc_*`와 독립적인 1회 지급이다. 기존 슬롯에서 목적지를 먼저 발견했어도 드레이크의 항로 조사는 진행된다.
- 표의 XP는 2일차 콘텐츠의 기준치다. 기존 장소 첫 발견 XP, 휴식 숨결, 감쇠와 이전 구간에서 넘어온 XP에 따라 실제 Lv20 경계에 닿는 시점은 달라진다.
- 전투는 경로마다 일반 19 × 4 + 정예 2 × 12 = 기본 100 XP를 목표로 한다. 기존 적을 여러 소규모 무리로 나누고, 처치 XP는 기존 전투 경로에서 지급한다. 무리 수와 구간 시간은 초행 플레이테스트에서 조정한다.
- 공중 조사 표식과 경로별 적 완료 상태를 슬롯에 저장한다. 재진입 시 완료한 표식과 처치한 임무 적은 유지하고, 남은 무리만 배치한다.
- Lv19의 XP가 가득 차지 않았다면 HUD에 남은 XP를 표시한다. 주변 기존 순찰에서 부족분을 채울 수 있다.

## 웜 진화 — 회피 시험

- **열림 조건** — 세 임무 완료와 Lv20 XP 경계 도달. `TRIAL_GATES`에 `{level: 20, trial: 'wyrm', name: '회피 시험'}`을 추가한다. 경계에서 화면상 Lv19가 가득 찬 상태로 대기하며, 시험 통과 뒤 기존 대기 XP를 정산한다.
- **시작** — 등불 사슬 섬 외곽에 진입한 뒤 시작 입력을 누른다. 표식 근처에서 예고 띠와 약점 노출을 연습할 수 있다. 본시험은 3초 카운트다운 뒤 90초다.
- **공격 예고** — 등불이 1.5초 점멸하고 띠와 경고음이 현재 공격선을 표시한다. 좌우 띠 → 상하 띠 → 엇갈린 띠를 순환한다. 표시 뒤 조준선을 고정해 예고한 자리로만 탄막을 보낸다. 회피는 기존 선회·상승·하강 조작을 쓴다.
- **약점 공략** — 탄막 피격 없이 해당 파동을 넘기면 등불의 핵이 4초간 드러난다. 기존 기본 공격이나 브레스로 핵에 한 번 명중하면 파동이 해결된다. 약점 창을 놓치면 해당 패턴부터 다시 시도한다.
- **성공** — 제한 시간 내 서로 다른 세 파동에서 각각 회피와 핵 명중을 달성한다. `growth.trials.wyrm`을 슬롯에 저장하고 웜 진화와 대기 XP 정산을 실행한다. 시험 XP는 0이다.
- **실패와 재도전** — 90초 초과, 시험 탄막 3회 피격, 체력 0 또는 시험 경계 이탈 시 실패다. 피격한 파동에서는 핵이 열리지 않는다. 사슬 섬 바깥의 안전 비행 체크포인트로 돌려보내고 재시작 입력을 기다린다.
- **저장·복구** — 시험 중 재접속은 안전 체크포인트에서 재대기한다. 본시험 전 HP를 복구해 연습 및 재시도의 상태를 맞춘다. 각 시도는 타이머·피격·핵 진행을 초기화한다.
- **난이도 메모** — 중간. 기존 탄체·브레스 충돌·배너를 재사용하고, 예고 표시·패턴 타이머·노출 중인 핵의 피격 판정이 필요하다. 패턴마다 지형 밖에 두 방향 이상의 탈출로를 확보하고 터치 조작에서도 확인한다.

### 시험 HUD와 판정 순서

| 시점 | HUD 피드백 |
|---|---|
| 카운트다운 | 준비 숫자 3 → 2 → 1 |
| 예고 시작 | 공격 띠와 점멸, 위치 고정 |
| 탄막 통과 | 회피 성공 또는 피격 횟수 표시 |
| 핵 노출 | 남은 공격 기회 4초 표시 |
| 핵 명중 | 해결한 파동 수 1/3 → 3/3 |
| 실패 | 시간 초과·피격·이탈·체력 소진 중 실제 사유 표시 |

- 시험 전용 탄체만 시험 피격 카운터에 반영한다. 연습과 본시험 중 기존 순찰 무리가 시험 공간으로 들어오지 않게 배치한다.
- 마지막 핵과 실패 조건은 한 번만 판정한다. 제한 시간이 끝나거나 치명타를 받은 프레임에서는 실패 처리를 먼저 한다.
- 카운트다운과 연습은 본시험의 90초에서 제외한다. 소리 없이도 공격 띠와 핵 노출을 구별할 수 있게 한다.

## 스토리 확인 필요

- **확인 필요 · 알의 설정** — ‘마지막으로 알려진 알’ 문구와 기존 ‘마지막 알’의 관계. 이번 대사는 알을 언급하지 않는다.
- **확인 필요 · 연맹의 회색 동기** — 숨결을 봉인한 주체와 섬을 지키려 했다는 동기. 이안은 관찰한 신호와 옛 기록의 차이만 말한다.
- **확인 필요 · 등불의 용도** — 봉인 등불 해방과 마을 등불 유지의 관계. 여기서 풍향탑에 렌즈를 끼우는 행위는 신호 복구에 한정한다.

## 구현 체크리스트

- [ ] **P0 · `ground.js`** — 신규 임무 단계와 자원·렌즈·설치 플래그를 슬롯에 추가하고, 기존 첫 임무 단계는 그대로 읽는다. 1편 완료와 드레이크 진화를 진입 조건으로 확인한다.
- [ ] **P0 · `ground.js`** — 기존 공터의 착륙·폴리모프·상호작용 흐름에 이안, 단계별 채집, 작업대 레시피, 풍향탑 렌즈 설치, `say()` 대사를 연결한다. 자원 소비와 단계 완료를 함께 저장한다.
- [ ] **P0 · `game.js` / `growth.js`** — SITES 중심으로 바깥 표식을 배치하고 표식 통과·전용 무리 처치·보고 상태를 연결한다. `REWARDS` 지급에 `quest_*`, `craft_*`, `survey_*` 접두 키를 사용해 기존 1회 보상과 함께 저장한다.
- [ ] **P0 · `game.js` / `growth.js`** — 진화 게이트, 패턴·핵·타이머, 재시도 체크포인트를 연결한다. 이미 웜 이상인 저장 슬롯에는 기존 형태를 유지하도록 웜 경계 통과 상태를 마이그레이션한다.
- [ ] **P1 · `game.js` / `ground.js`** — 동일 HUD 단계 ID로 하늘·지상 목표를 표시하고, 거리·카운터·제한 시간은 별도 HUD 필드로 갱신한다. 실패와 성공 시 시험 탄체·표식을 정리한다.
- [ ] **P1 · Claude 검증** — 기존 발견 완료 슬롯과 새 슬롯, 임무 중 재접속, 제작·보고 반복 입력, Lv19 XP 상한과 재도전을 재현한다. 정상 경로 XP와 실제 원천별 XP·누적 시간을 각각 기록한다.
