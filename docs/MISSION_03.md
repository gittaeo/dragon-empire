# 제안·사용자 확인 대기 — 미션 03: 하늘 지붕의 메아리

웜(Lv20)이 북쪽과 동쪽의 신호를 대조해 하늘 지붕 봉우리의 시험을 찾는다.
시험을 통과하면 드래곤 엠페러(Lv30)로 진화하고, 처음 길을 알려 준 풍향탑 공터로 돌아온다.
시간과 수치는 1배속 초행 플레이테스트용 제안이다.

## 페이싱과 XP

| 순서 | 플레이 | 시간 | 퀘스트 | 탐험 | 제작 | 전투 |
|---|---|---:|---:|---:|---:|---:|
| 1 | 북쪽 끝의 응답 | 17~23분 | 220 | 150 | 90 | 150 |
| 2 | 동쪽 탑의 두 박자 | 17~23분 | 240 | 150 | 90 | 150 |
| 3 | 하늘 지붕의 문턱 | 19~27분 | 260 | 150 | 0 | 150 |
| 시험·4 | 최종 시험, 대관식, 우리가 알던 날개 | 7~17분 | 0 | 0 | 0 | 0 |
| 합계 | 3~4일차, 누적 170~210분 목표 | 60~90분 | 720 (40%) | 450 (25%) | 180 (10%) | 450 (25%) |

- 3일차는 북쪽과 동쪽 조사, 여유가 있으면 봉우리 준비까지 진행한다. 봉우리 보고가 4일차의 재개 지점이 될 수 있다.
- 누적 목표는 M2 종료 시간과 함께 실측한다. 실제 날짜 잠금 없이 이어서 진행할 수 있다.
- 전투는 각 현장의 계획된 무리 기준이다. 휴식 숨결·50분 창 감쇠·이월 XP·주변 사냥에 따라 실제 경계 도달 시간은 달라진다.
- Lv29 XP 바가 찰 때까지 시험을 대기한다. 부족하면 HUD에 차이를 표시하고 기존 주변 순찰을 이용한다. 먼저 차면 봉우리 보고를 계속 안내한다.

## 장소와 비행 여유

| SITES ID | 기준 중심 (x, y, z) | 사용 |
|---|---|---|
| isle_n | (-468, 205, -2304) | 섬 외곽의 수평 접근과 상승 이탈 |
| tower_e | (1200, 127, -360) | 감시탑 측면의 시차 신호와 경비 |
| peak | (2550, 1115, 2200) | 능선 바깥의 상승 조사와 최종 시험 |

- 지상은 풍향탑 공터 한 곳이다. 기존 PAD는 공터 중심 동쪽 50m이며 XZ 좌표는 (-66.5, 1410)이다. 착륙 후 뿔과 꼬리가 보이는 여성 폴리모프로 NPC와 작업대를 이용한다.
- 웜은 scale 3, 몸길이 약 27m다. 표식 중심 판정 반경은 45m, 대관식 이후 귀환 표식은 65m로 제안한다. 고리 표시 크기도 판정에 맞춘다.
- 기존 `[site, side, up]`와 `markerPos`를 사용한다. M3는 비행 통로 안에서 표식 중심과 지형·장애물 사이에 판정 반경 + 30m 이상을 확보한다.
- 고도 상한과 장애물 검사 실패 시 바깥쪽 접근점으로 옮긴다. seed 7에서 양방향 진입, 좁은 탑 사이를 우회하는 경로, 웜·엠페러 카메라 시야를 확인한다.
- 표식 통과는 플레이어 중심의 프레임 간 이동 선분으로 판정한다. 근처 적은 공중의 안전 위치에 배치하고 용형에서 진행한다.

## 1. 북쪽 끝의 응답

1. 공터에서 세라에게 풍향탑의 새 점멸을 듣는다. 가지·돌·숨결 파편을 모아 작업대에서 바람받이를 제작한다.
2. 북쪽 끝 섬 외곽에서 낮은 표식과 높은 표식을 차례로 통과한다. 올라서 돌아보면 한 점멸이 두 번 보이는 이유를 고도차로 읽을 수 있다.
3. 순찰을 나눠 상대한다. 열린 선회 공간에서 웜 브레스의 관통이나 연쇄를 활용해 간격이 좁아진 적을 한 번에 정리할 수 있다.
4. 공터로 돌아와 이안에게 보고한다. 이안은 같은 간격이 동쪽 탑의 기록에도 있음을 알아본다.

## 2. 동쪽 탑의 두 박자

1. 공터에서 이안에게 탑의 옛 점멸표를 받는다. 탑 양쪽 바깥의 표식에서 신호 지연을 비교한다.
2. 사슬 기사와 기수의 경비를 정리한다. 탑 바깥으로 크게 돌면 경비의 사격선과 다음 접근 방향을 함께 볼 수 있다.
3. 공터로 돌아와 바람받이를 공명 조율기로 개량한다. 이안이 두 기록을 포개 하늘 지붕 봉우리의 방향을 잡는다.

## 3. 하늘 지붕의 문턱

1. 공터에서 세라가 봉우리의 점멸을 읽는 법을 알려 준다. 조율기는 진입에 앞서 풍향탑에 설치한다. 봉우리 등불의 위험 띠 경고와 핵 노출은 설치된 조율기의 신호에 동기화된다.
2. 용형으로 올라가 능선 바깥 표식 두 곳을 확인한다. 조율된 풍향탑 신호와 같은 박자로 봉우리의 등불이 반응한다.
3. 시험 입구 외곽의 경비를 정리하고 공터의 이안에게 두 단서를 보고한다. 보고와 레벨 경계가 충족되면 시험 시작 표식이 나타난다.

## 최종 시험 — 봉우리의 공명

- **개방** — M3 1~3 완료, 공명 조율기 설치 확인, 미통과, Lv29 XP 바 충족. `TRIAL_GATES`에 `{level:30, trial:'emperor', name:'봉우리의 공명'}`을 추가한다.
- **시작** — 용형으로 봉우리 바깥 주황 표식에 닿으면 체력을 채우고 3초 카운트다운을 시작한다. HUD에 남은 시간, 피격 횟수, 공명 진행을 표시한다.
- **이동** — 본시험 150초 안에 넓은 표식 세 개를 순서대로 통과한다. 수평 선회, 상승 뒤 선회, 바깥쪽 하강으로 잇고 각 구간에 재접근 공간을 둔다.
- **전투와 장비** — 각 표식 통과 직후 공명 조율기가 위험 띠를 2초 예고한다. 띠는 발사 전에 위치가 고정되며, 회피하면 조율기가 핵을 5초 드러낸다.
- **판정** — 두 혈통의 기본 사격으로 핵을 한 번씩 맞힌다. 띠 피격 또는 핵 창 만료 시 그 표식의 공격부터 반복한다. 남은 시간은 계속 흐른다.
- **성공** — 세 번째 핵 명중 시 시간·체력·경계 조건을 확인하고 `growth.trials.emperor`를 저장한다. 기존 레벨 처리로 대기 XP를 한 번 정산해 Lv30 대관식을 발동한다.
- **성공 XP** — 시험 보상은 0. Lv29→30의 경계 해제와 초과분 정산은 성장 전이로 처리한다. 필요한 내부 진화 트리거를 퀘스트 XP로 집계하지 않는다.
- **실패** — 150초 소진, 시험 띠 3회 피격, HP 0, 시험 경계 이탈 시 실패한다. 띠 하나에서 피격은 최대 1회 집계한다.
- **재도전** — 경계는 봉우리 중심 기준 반경 780m. 시험 오브젝트를 정리하고 시작 표식 바깥 안전점으로 복귀한다. 시작 표식을 다시 통과하면 체력·타이머·표식·핵을 초기화한다.
- **접속 복구** — 재접속은 안전점에서 대기한다. 시도 도중의 시간과 피격은 초기화하고 조율기 설치, 조사, 보상, 초과 XP는 슬롯에서 복구한다.
- **난이도 중간** — `TRIAL_WYRM`의 띠·탄 충돌·핵 노출·카운트다운을 재사용한다. 표식과 파동을 묶는 상태 전이, 전용 안전 복귀, 사망·스폰 처리 연결이 추가된다.

### 루세르나와의 연결 및 확인 항목

- 시험 대상은 봉우리의 봉랍 등불 세 개가 내는 **날갯짓의 잔향**으로 제안한다. 기존 띠·핵으로 표현하며, 등불의 박자가 대관식 이후 루세르나의 탄막을 예고한다.
- `WORLD.md`의 보스 격파 후 진화 서술과의 충돌은 **조율 시험 → 대관식 → 황제의 하늘 → 본체** 순서를 채택하는 안으로 정리한다. 현행 본체 첫 출현 조건은 대관식 45초 뒤다.
- **확인 필요 · 마지막 알** — 종 전체의 마지막 알인지, 기록에 남은 마지막 알인지. 이 구간의 대사는 알의 수를 언급하지 않는다.
- **확인 필요 · 연맹의 회색 동기** — 마을의 생존 때문에 등불을 유지했다는 설정의 채택 여부. 기록에는 항로 점멸과 사격의 관계만 나타난다.
- **확인 필요 · 루세르나 해방 여부** — 본체를 쓰러뜨릴지, 구속을 풀지. 시험의 결과는 봉우리 항로를 여는 데까지다.

## 4. 우리가 알던 날개 — 진화 직후 귀환

1. 대관식이 끝나면 첫 목표에 풍향탑 공터를 띄운다. 큰 외곽 표식이 골짜기 아치 옆에서 PAD로 내려가는 방향을 알려 준다.
2. 공터에 접근할 때 세라와 이안이 하늘을 올려다보고 PAD 쪽으로 몸을 돌린다. M3 전반에 장비와 기록을 보던 두 사람이 처음으로 비행하는 주인공을 먼저 바라본다.
3. 착륙해 여성 폴리모프로 다가가면 세라가 날갯짓을 알아보고, 이안은 돌아오는 용을 위해 항로등을 켠다. 대사는 아래 데이터의 세라·이안 두 단계로 이어진다.
4. 첫 귀환은 강제 이동 없이 안내한다. 대사 진행은 슬롯에 남아 비행이나 귀환 보상 후에도 이어갈 수 있다.

## 데이터 연결 규칙

- 아래 `M3` 배열은 `quests.js`의 M2와 동일한 키 구조다. `trial`, `tuning`, `rewards`는 연결용 설정이며 임무 단계 종류는 여섯 가지를 재사용한다.
- M3의 시작 조건은 첫 지상 임무 완료, M2 완료, 웜 시험 통과 및 Lv20 이상이다. 마지막 귀환 단계는 엠페러 진화와 대관식 종료 후 활성화한다.
- M3 진행은 `growth.quests.m3`에 `m/s/n`으로 저장한다. M2의 기존 평면 `m/s/n`을 읽어 현재 진행 상태를 보존한다. 임무 적 태그엔 임무 ID를 포함한다.
- 조사 XP는 `markers` 완료에 붙인다. 세 대상의 일반 발견은 M3 성장 구간에서 지도에 기록하고 XP는 각 150 조사 보상에 통합한다. 이전 발견·보상 기록은 보존하며 조사 보상은 해당 기록과 독립적이다.
- `clear`는 사이트별 29기를 네 차례로 나눠 내보낸다. 단계가 지정한 적 처치 수와 다음 배치 위치를 복구하고, 해당 처치 XP를 기존 전투 원천으로 집계한다.
- 무리당 합계는 나방 5×2.8, 기수 14×4, 사슬 기사 10×8로 기본 150 XP다. M3 태그 적의 기본 XP를 아래 값으로 지정하고 기존 전투 예산·휴식 보정을 한 번만 적용한다.
- 채집 묶음과 부족분 보충은 기존 공터를 이용한다. 제작물 소비·설치·단계 전이·보상 키는 함께 저장하고, 장비 설치 플래그는 시험에서 재사용한다.

## Claude Code 구현 체크리스트

- [ ] **P0 · 성장·마이그레이션** — `TRIAL_GATES`에 30 경계를 추가한다. `syncTrials`로 기존 Lv30 슬롯을 통과 처리해 형태를 보존한다. 기존 엠페러도 선행 임무를 마치면 M3 1~3을 진행할 수 있게 하고, 봉우리 보고 뒤 귀환 대사를 연다.
- [ ] **P0 · 임무 실행기** — M3 슬롯 상태, 임무별 적 태그와 소그룹 복구, PAD 안내, 조율기 설치 조건을 연결한다. 설치 프롬프트와 재료 부족 메시지에는 현재 단계의 아이템 이름을 사용한다.
- [ ] **P0 · 성장 보상** — `REWARDS.quest/craft`에 키를 추가하고 조사 키는 `REWARDS.survey`에서 관리한다. `discovery_m3_…`로 1회 지급하고 기존 `disc_…`와 구분한다. JSON의 단계별 보상 튜플과 표가 일치하는지 검사한다.
- [ ] **P0 · 최종 시험** — 웜 시험의 공용 판정을 연결하고 활성 시 주변 적 스폰과 일반 사망 처리를 제어한다. 피격·HP 0·이탈·시간 초과 후 안전 복귀, 경계 해제의 1회 저장, 대기 XP의 이중 집계 방지를 검증한다.
- [ ] **P1 · 귀환 장면** — 기존 대관식 완료 이벤트로 귀환 HUD를 열고 PAD 접근의 주민 반응, 공터의 여성 폴리모프 대사, 1회 완료 저장을 연결한다. 본체 출현 타이머와의 동시 동작을 확인한다.
- [ ] **P1 · 1배속 검증** — 두 혈통과 키보드·터치에서 웜/엠페러 경로를 비행한다. 기존 Lv29/Lv30 슬롯, 조기 발견, 컷신 중 재접속, 장비 소비 직후 재접속, 시험 재도전을 재현한다. 구간 60~90분·누적 170~210분과 XP 원천 비중을 각각 기록한다.
