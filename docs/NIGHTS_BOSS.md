# 루세르나 — 풍향탑 압박 설계

2026-11-21 · Codex → Claude · 제안, 수치는 사람 플레이 전 가설

셋째 밤 웨이브 종료 → 엠페러 대관 → 루세르나 전투 → 보스 격파로 승리. 용의 생존뿐 아니라 탑을 지킬 이유를 만든다. 기존 `spawnBoss`·`updateBoss`·보스 HP 바를 활용하며 탐험 모드 설정과 분리한다.

## 탑 공격: 등불 낙하

| 단계 | 초기 가설 | 플레이어 신호 |
|---|---|---|
| 대기 | 보스 등장 후 10초, 이후 **20초 간격**. 한 번에 공격 1개만 | 보스가 탑 쪽으로 선회하며 음성/배너 |
| 예고 | **4초**. 탑 주변 고정 표식과 하늘→탑 경로, 남은 시간 표시 | 주황 원·상승하는 경고음, 원 안의 숫자로 탑 위협을 명시 |
| 비행 | 요격 가능한 등불 투사체가 탑으로 **5초**에 접근 | 붉은 구슬·경로·화면 밖 화살표. 일반 습격자와 모양을 구분 |
| 결과 | 탑 도착 시 **HP 12** 피해 1회. 투사체 파괴 시 0 | 탑 HP 변화와 타격 효과 / 파괴 시 성공 피드백 |

위 숫자는 첫 실험용이다. 플레이어가 보스를 향해 공격하면서도 경고를 볼 수 있어야 한다. 탄의 HP는 일반 브레스가 실제로 맞는 판정과 관통/광역 스킬을 확인한 뒤 설정하고, 시작값 300은 임시값이다. 타격 판정은 시간 종료와 충돌 중 한 경로만 채택하며 중복 피해를 금지한다. 탑 공격은 피하기만 해서는 막히지 않는다: 플레이어가 투사체를 파괴해야 하고, 기존 방향 방어막과의 상호작용은 아래 계약을 따른다.

기존 플레이어 대상 탄막/나방 소환과 신호가 겹치지 않게 예고 중에는 새로운 탄막·소환을 시작하지 않는다. 기존 투사체는 지속하되 화면 부하가 심하면 미리 정리하는 방안을 사람 테스트 후 결정한다. 탑 공격과 기존 탑 습격자 AI의 추적·화살표 목록은 별도 타입으로 관리하고 중복 집계하지 않는다.

## 데이터 계약 (제안)

```js
const TOWER_ASSAULT = {
  initialDelay: 10, cooldown: 20, telegraph: 4, travel: 5,
  damage: 12, projectileHp: 300, maxActive: 1,
  shieldPolicy: 'no-block', // 탑 공격은 요격으로만 대응; 방향 방어막과 혼동 방지
};
// 상태: idle → telegraph → travel → resolved → idle
// 이벤트 예시(초 단위 게임 시간):
{kind: 'tower_assault', id, phase: 'telegraph', remaining, target: {x,y,z}}
{kind: 'tower_assault', id, phase: 'travel', remaining, hp, position}
{kind: 'tower_assault', id, phase: 'resolved', result: 'intercepted' | 'impact' | 'cancelled'}
```

`cooldown`은 **해결 시점부터** 시작한다(예고 시작 간격은 약 29초). 일시정지·탭 비활성 중에는 게임 시간과 공격 상태를 함께 멈춘다. 대관 중 공격하지 않으며, 패배·보스 사망·재시작 때 표시·투사체·타이머를 정리한다. 게임 종료가 이미 처리된 경우 추가 피해/승리 이벤트를 막는다. 탑 HP가 0 이하가 된 프레임에는 패배 우선; 보스가 같은 프레임에 처치되어도 승리하지 않는다. 이벤트 순서를 테스트로 고정한다.

방어막은 낮에 예보된 **일반 습격 방향**에만 작동한다. 보스 투사체에는 막음 효과를 주지 않고 명시적으로 안내한다. 다른 동작을 택한다면 별도 결정 후 충전 소모·피해량을 계약으로 고정한다. 나중에 유료/랜덤 시스템 없이 조정 가능하게 수치는 모드 전용 데이터로 둔다.

## HP와 체감 시간

HP 15,000은 현재 구현값이지 검증된 밸런스가 아니다. **초행 성공 플레이에서 보스가 활성화된 순간부터 처치까지 90~150초**를 실험 목표로 제안한다. 10초 후 예고, 이후 29초 주기면 이 기간에 대략 3~5회 경고를 경험할 수 있다(격파 시각·일시정지 제외 여부에 따라 달라짐). 손 플레이의 유효 DPS 중앙값을 D라고 하면 `목표 HP ≈ D × 목표 초`로 조정한다. 자동 즉시 처치나 완벽 조준 봇 시간은 난이도 근거가 아니다.

먼저 초행 3명 이상에서 보스 활성 시간, 생존/승패, 탑 HP 시작·최저·종료, 탑 공격 예고·요격·명중 횟수, 실제 적중률과 보스 피해량을 기록한다. 90~150초가 한 판 15분 목표를 넘기면 공격 빈도 및 전체 웨이브 길이와 함께 조정한다. 미터법은 사람이 플레이한 경우와 봇을 구분해 저장한다.

## 구현·검증 체크리스트

- [ ] 세 밤 전용 설정과 상태 머신, `id`별 최대 1회 결과 및 탑 피해.
- [ ] 예고·경로·실제 판정 일치, 화면 밖 위치와 높은 고도/장애물에서의 가시성 확인.
- [ ] 브레스·스킬 요격, 빗나감, 화면 밖·충돌 누락, 탑 근접 발사와 HP 0 동시 상황 테스트.
- [ ] 일시정지·탭 복귀·보스 사망·탑 파괴·플레이어 사망·재시작 중복 정리.
- [ ] 기존 탐험 보스 회귀와 시드 재현성(확률 요소를 추가할 때만 별도 스트림 사용).
- [ ] 데스크톱·모바일 실기기와 초행 손 플레이에서 가독성·시간 측정. 우선순위가 충돌하면 탑 공격을 끄고 보스 단독 전투로 출시 범위를 줄인다.
