# 첫 낮 온보딩 — 구현 설계

2026-11-21 · Codex → Claude · 문구와 트리거 제안, 사용자/플레이 테스트 전 확정 아님.

목표: 첫 낮 60초 동안 플레이어가 채집→작업대→한 가지 제작→해질녘 자동 비행→밤 요격을 배운다. 첫 판의 실제 시간을 멈추지 않는다. 안내는 화면의 작은 고정 영역에 한 번에 하나, 기존 목표 HUD·방어막/탑 HP·예보와 겹치지 않게 표시한다. 버튼/키 설명은 현재 입력 방식에 맞춘다. 도착 전에 자동으로 다음 단계로 넘어가지 않고, 안내에 실패·타이머 만료 경로를 둔다.

| 순서 | 표시 문구(PC) | 표시 조건 | 종료 조건 |
|---|---|---|---|
| 1. 이동·채집 | **WASD 이동 · 마우스 오른쪽 드래그 시점**<br>**빛나는 재료에 다가가 E** | 1번째 낮 시작, 로딩·시작 화면 종료 후 | 첫 재료 실제 획득 시 2로, 또는 낮 종료 시 해질녘 안내로 |
| 2. 필요한 재료 | **가지 1 · 돌 2 · 숨결 파편 1을 모으세요**<br>**수리를 원하면 가지 2 · 돌 1** | 첫 획득 후, 재료 부족 시 | 둘 중 하나를 제작할 만큼 가방에 갖추면 3으로. 조건은 실제 레시피 데이터 사용 |
| 3. 작업대 | **작업대로 가서 E**<br>**오늘은 방어막 또는 수리 중 선택** | 레시피 하나 이상 충족 | 작업대 메뉴가 실제 열리면 4로, 낮 종료 시 해질녘 안내로 |
| 4. 선택 | **방어막: 예보 방향 6회 차단**<br>**수리: 풍향탑 HP +30** | 첫 작업대 메뉴가 열릴 때. 탑이 가득 차면 '탑이 가득 차 수리할 수 없음' 표시 | 실제 제작 완료 시 5로. 메뉴 닫기/시간 만료 시 문구 제거, 상황에 맞게 3으로 복귀 또는 해질녘 안내 |
| 5. 결정 결과 | **[방향] 방어막 준비 · 반대쪽을 먼저 지키세요** 또는 **풍향탑 수리 완료** | 실제 제작 성공 직후 | 4초 뒤 숨김. 추가 제작을 금지한다고 단정하지 않음(이월 재료 존재) |
| 6. 해질녘 | **시간 종료! 자동으로 용이 되어 이륙합니다** | 해질녘 진입, 가방이 비어도 표시 | 이륙 완료 또는 5초 뒤 숨김; 실제 자동 변신 실패 시 '넓은 곳으로 이동' 안내는 구현 상태에 맞게 별도 처리 |
| 7. 첫 밤 | **예보 방향에서 오는 등불을 막으세요**<br>**우클릭 시점 · 클릭/F 브레스** | 1번째 밤, 플레이어가 실제 비행 중 | 첫 습격자 격파 또는 8초 후 숨김. 화살표/기둥과 함께 현재 목표는 유지 |
| 8. 피해·방어 | **풍향탑이 공격받고 있어요! 붉은 등불을 막으세요** | 첫 탑 피해 또는 방어막 차단 시 1회 | 4초 후 숨김. 방어막 차단은 별도 문구 **방어막이 막았습니다 · 남은 횟수는 탑 표시** |

터치 대안: `WASD 이동`→`왼쪽 조이스틱 이동`, `E`→실제 상호작용 버튼 명칭, `우클릭`→실제 시점 조작, `클릭/F`→실제 브레스 버튼. 명칭은 구현과 대조해 확정한다. 모바일 지원은 실기기 검증 전 확약하지 않는다.

## 구현 계약·예외

- 안내 진행은 별도 `tutorialStep` 상태와 획득/메뉴/제작/피해 이벤트로 갱신한다. 단순 배너 타이머가 아닌 실제 성공으로 진행; 첫날 채집물을 무작위 추측하지 말고 현재 `DAY_ITEMS`와 `RECIPES_N`을 사용한다.
- 첫 낮이 시작할 때 남은 시간이 60초 그대로 시작해야 한다. 안내를 읽을 시간을 벌기 위해 묵시적으로 시간을 일시정지하거나 60초를 늘리지 않는다. 타이머 0에서 단계가 남아도 dusk로 이동한다.
- 재료 미완료·작업대 미접근·제작 실패·팝업 열림 채로 시간 종료 시 밤이 정상 시작된다. 텔레포트·자동 제작·무료 방어막은 제공하지 않는다.
- 첫 밤 안내는 낮 안내를 덮어쓰고, 패배·승리·일시정지 오버레이와 겹치면 숨긴다. 재시작 시 첫 판 안내 반복을 기본으로 하되 나중에 건너뛰기 선택 가능. 오픈월드 슬롯/저장을 수정하지 않는다.
- 최초 재료가 가방에 이미 있거나 한 번에 레시피가 충족되는 경우 현재 가방을 기준으로 단계 건너뛰기. 수리 불가 이유를 안내하고 방어막 레시피만 충족한 경우에도 멈추지 않는다.
- 표시·비표시 조건과 E/터치 입력, 제작 성공/실패, 메뉴 닫기, 시간 만료, 재시작·일시정지, 화면 크기별 겹침을 테스트한다. 초행 3명 이상에게 도움 없이 성공 여부·소요 시간을 측정하고 실제 보이는 채집물과 작업대 방향을 확인한다. **60초에 충분한지는 현재 미검증**.
