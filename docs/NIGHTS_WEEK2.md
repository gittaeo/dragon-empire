# 풍향탑의 세 밤 — 2주차 구현 제안

2026-11-21 · Codex → Claude · 설계 초안, 수치와 긴급 착륙은 플레이 테스트로 결정

## 셋째 밤과 대관

1. 3밤 일반 웨이브가 모두 끝난 뒤 `boss_intro`로 전환한다. 남아 있는 밤 적을 정확히 정리하고, 용을 Lv.30 엠페러로 진화시킨 뒤 기존 `startCoronation()` 연출이 끝나면 루세르나를 호출한다. 이 모드의 자동 타이머는 계속 비활성화한다.
2. 보스는 기존 `spawnBoss`/`updateBoss`와 HP 바를 재사용하되 세 밤 전용 HP·공격 간격은 매개변수로 분리한다. 기존 자유 탐험의 20,000 HP와 위계 경험치를 그대로 쓰지 말고 실측 시간으로 조정한다. 대관 중 무적·적 제거 효과가 탑 방어 판정을 생략하지 않는지 확인한다.
3. `boss_active`에서는 보스 격파를 명시적으로 감지해 승리한다. 탑 0과 용 사망은 항상 패배로 우선 처리한다. `nightEnemies() === 0`만으로 승리하지 않는다. 보스 소환 나방은 탑을 공격할지 명확히 정의하고, 밤 적 추적에 포함해 화면 표시와 정리도 일치시킨다.
4. 연출 도중 일시정지·탭 이탈·재시작·모델 로딩 실패를 고려하고, 보스 중복 생성과 중복 결과 화면을 방지한다. 15분 초과나 가독성 저하 시 셋째 밤 마지막 웨이브를 보스전으로 대체한다.

## 긴급 착륙 실험 (기본 비활성)

밤에 착륙 후 인간형으로 수리할 수 있지만, 탑과 적·탄·시간은 계속 진행한다. 기존 지상 안전구역의 적 제거 및 전투 정지를 그대로 쓰면 무적 정지 악용이 되므로 상태별 업데이트 분리가 선행돼야 한다. 착륙 실패·변신 중 피해·인간형 사망·재이륙 위치를 별도로 정의한다. 조작 비용과 1회 수리량은 직접 플레이 후 결정하며, 우선 플래그로 켜는 별도 실험으로 두고 가독성이나 조작이 나쁘면 출시 범위에서 제외한다.

## 웨이브 다양화

- 기존 탑 돌진형과 플레이어 추격형 2종만 사용한다. 화면에서 역할을 색상·실루엣·표식으로 구별하고, 예보 방향과 실제 이동 방향이 일치해야 한다.
- 좌우 번갈아 출현하는 기본 패턴, 한쪽 두 번 연속 공격하는 변형을 고정 시드로 재현 가능하게 실험한다. 동시에 보이는 표식·적 숫자는 제한한다.
- 방어막은 충전 수와 대응 방향을 HUD에 표시하고 피격마다 반응을 보인다. 방향 중복 구입과 잘못된 방향 표시를 막는다.
