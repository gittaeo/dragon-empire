# 영구 성장 페이싱 v0.1 — 해츨링에서 엠페러까지 3~4일 (제안, 사용자 확인 대기)

작성: Codex(게임 디자이너 초안) + Claude(코드 기준 검토·통합) · 2026-11-21
상태: **검증 전 가설**. 사용자가 확정한 것은 "영구 저장 + 새 슬롯", "성체까지 3~4일, 퀘스트·탐험·진화를 함께"뿐이다. 아래 숫자는 모두 플레이테스트로 조정한다.

## 1. 하루의 정의 (확인 필요)
| 가정 | 값 |
|---|---|
| 하루 플레이 | **50~60분 세션 1회**(선택적으로 2회) |
| 엠페러까지 누적 | **170~210분** — 순조로우면 3일차 끝, 여유 있게 탐험하면 4일차 |
| 진화 판정 | 날짜가 아니라 **레벨 + 진화 시험 완료**(실제 시간 잠금 없음) |

## 2. 단계별 목표
| 일차 · 누적 | 목표 | 진화 조건 (레벨 + 시험) | 필요한 콘텐츠 |
|---|---|---|---|
| 1일차 · 45~60분 | 해츨링 → **드레이크 Lv10** | 첫 임무 '꺼진 등불, 남은 숨결' 완료 + **비행 시험**(지형을 이용한 접근·마무리) | 첫 임무(구현됨) + 첫 발견지 1곳 + 장비 1개 제작 |
| 2일차 · 95~120분 | 드레이크 → **웜 Lv20** | 지역 퀘스트 한 줄기 + **회피 시험**(예고 공격 회피·약점 공략) | 임무 2~3개, 발견지 3곳, 장비 개량, 엘리트(구현됨) |
| 3~4일차 · 170~210분 | 웜 → **엠페러 Lv30** | 발견 단서로 최종 퀘스트 개방 + **최종 시험**(이동·전투·제작 장비 종합) | 임무 3~4개, 최종 시험(루세르나 연계 후보), 대관식(구현됨) |
| 엠페러 이후 | 황제의 하늘(구현됨) | 위계·보스·귀환 보상 유지 | — |

**성장의 맛 3순간**: ① 드레이크가 되어 첫 임무 근처 높은 지형에 처음 착지 ② 웜 브레스로 익숙한 적 무리를 한 번에 무너뜨림 ③ 엠페러가 되어 풍향탑 마을로 돌아가 달라진 주민 반응을 봄.

## 3. XP 원천과 반복 사냥 억제
| 원천 | 비율(정상 경로) | 지급 시점 |
|---|---|---|
| 전투 | 25% | 처치 (임무 중 처치 포함) |
| 퀘스트 | 40% | 임무 완료 1회 |
| 탐험·발견 | 25% | 장소 최초 발견 1회 |
| 제작 | 10% | 첫 완성·개량 1회 |

- **반복 사냥 감쇠**(Codex 안): 같은 무리 처치 XP를 세션 내 1~5회 100% → 6~10회 25% → 이후 0%, 카운터는 슬롯에 저장하고 실제 플레이 50분마다 갱신.
- **Claude 수정 제안**: 0%는 "사냥해도 아무것도 안 오르는" 좌절을 줄 수 있어 **최저 10%**로 두고, 대신 **휴식 숨결**(접속하지 않은 시간에 쌓이는 다음 세션 XP 보너스 ×2, 최대 한 레벨분)로 "오늘은 여기까지"를 자연스럽게 유도.
- 시험을 끝내기 전에는 다음 단계로 진화하지 않음(레벨 상한에서 대기). 대기 중 XP는 한 레벨분까지 이월.

## 4. 수치 초안 (P0)
| 항목 | 현재 | 제안 |
|---|---|---|
| Lv1→10 총 XP | 800 (Lv30까지 총 9485, 완벽 조준 봇 약 6분) | **1,000**, 초반 빠르게 배분 |
| Lv10→20 / Lv20→30 | — | **1,200 / 1,800** (구간 총량) |
| 처치 XP | `round5(8+2L)` | **일반 4 / 정예 12**부터 실측 |
| 퀘스트·발견·제작 XP | 없음 | 단계 구간 총량 × 위 비율을 콘텐츠 수로 나눔 |
| 진화 | 레벨만 | 레벨 + 시험 완료 플래그(슬롯 저장) |

> Claude 검토: 위 총량(4,000 XP)에 전투 25% = 1,000 XP ÷ 처치 4 XP ≈ 250처치. 현재 봇이 분당 약 40처치라 전투만으로는 약 6분 → **나머지 75%가 콘텐츠에서 나와야 하므로, 3시간을 채우려면 임무 7~9개 + 발견지 8~10곳 + 시험 3개 분량이 필요**하다. 콘텐츠 없이 XP만 줄이면 "느리고 지루한 사냥"이 되므로 **수치 변경은 콘텐츠와 함께 단계적으로** 적용한다.

## 6. 사용자 확인이 필요한 결정
1. 하루 = 50~60분 1회 가정이 맞는지 (더 짧은 하루 20~30분 × 여러 날이면 총량을 줄여야 함)
2. 반복 사냥 감쇠를 0%까지 내릴지, 최저 10% + 휴식 숨결로 할지
3. 진화에 **시험(미니 퀘스트)을 필수**로 넣는 것
4. 기존 판 단위 보상(귀환 시 용의 결정)을 영구 성장에서 어떻게 유지할지 — 제안: 매 세션 귀환 시 그날 활동량 기준 지급 유지
