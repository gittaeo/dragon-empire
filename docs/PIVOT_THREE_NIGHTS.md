작성: Claude Code ↔ Codex 토론 (2026-11-21) · 상태: **사용자 결정 대기**
배경: 사용자 — "3~4일 영구 성장·오픈월드·임무 추가 방향은 1달 출시가 어렵다. 에셋은 살리고 용과 폴리모프(여성 인간형)를 핵심으로 다른 방향을."

## 2. 「풍향탑의 세 밤」 — 한 판 12~15분

| 단계 | 형태 | 하는 일 | 사용하는 기존 자산 |
|---|---|---|---|
| 낮 (45~60초) | **여성 폴리모프** | 공터에서 재료를 줍고 작업대에서 **탑 회복** 또는 **다음 밤 한 방향 방어막** 중 하나를 고름 | ground.js 착륙·변신·채집·작업대·풍향탑, 세라·이안 |
| 해질녘 | 변신 연출 | 용으로 돌아가 이륙, 밤이 옴 | timeofday.js 낮밤, 변신 VFX·사운드 |
| 밤 (3~4분) | **용** | 사방에서 오는 등불 군단 웨이브를 요격해 풍향탑(마을)을 지킴. 일부 적은 정해진 경로로 탑에 접근 | 비행·브레스·스킬 진화·콤보·엘리트, 적 3종 GLB |
| 아침 | 진화 | 밤을 버티면 진화: 1밤 해츨링 → 2밤 드레이크 → 3밤 웜 → 루세르나 직전 **엠페러** | 용 4단계 모델·대관식 연출 |
| 셋째 밤 끝 | 보스 | **루세르나** 격파 = 승리. 탑이 무너지면 패배 → 즉시 재시작 | 보스 GLB·탄막·보스바 |

- 재미의 핵심: **낮에 고른 준비가 밤의 요격 우선순위를 바꾼다**("동쪽에 방어막을 쳤으니 서쪽을 먼저 막자").
- 판 안에서 해츨링→엠페러까지 완주하는 성장(로그라이트 A의 장점)을 그대로 가져옴.

### Claude 추가 의견 (Codex 안과 다른 점)
1. **밤 중 긴급 착륙(2주차 확장 후보)**: 밤에도 공터에 내려 인간형으로 탑을 급히 수리할 수 있게 — 그동안 용은 무방비. 전투 한가운데서 변신을 고민하게 만드는 것이 이 게임만의 순간. 1주차 검증 후 넣을지 결정.
2. **재플레이 장치는 가볍게**: 매 판 웨이브 방향·구성 무작위 + 혈통(화염/폭풍) 선택 + 최고 기록(남은 탑 HP·시간) 로컬 저장. 영구 강화 상점은 컷.
3. **기존 작업은 버리지 않음**: 오픈월드 임무·영구 성장·저장 슬롯은 코드에 남기고 시작 화면에서 숨김("탐험 모드 — 개발 중"). 세 밤 모드는 별도 진입점, 기존 슬롯을 덮어쓰지 않음.

## 3. 4주 일정 (Codex 안 + Claude 보완)

| 주 | 마일스톤 | 판정 기준 | 컷 기준 |
|---|---|---|---|
| 1주 | 낮 1회 → 밤 1회 → 탑 승패 → 즉시 재시작 (적 1종) | 초행 플레이어가 도움 없이 변신·이륙하고, 낮의 선택이 밤에 무슨 차이를 냈는지 말할 수 있다 | 방어막 효과가 안 읽히면 '수리' 하나로 축소 |
| 2주 | 3밤 + 용 4단계 진화 + 루세르나, 시작→승리/패배→재도전 완주 | 15분 안에 완주, 콘솔 에러 0 | 보스와 웨이브가 겹쳐 안 읽히면 마지막 밤은 보스 단독 |
| 3주 | 사람 플레이 테스트로 낮 시간·착륙 동선·적 방향 조정, 밤 HUD·탑 피격 표시 정리, (선택) 밤 긴급 착륙 | 3명 이상 초행 테스트 | 터치 완주가 어려우면 모바일 공개 연기 |
| 4주 | 기능 동결. 재시작 시 상태 초기화, 로딩·오디오·전체화면, 배포 | 완주 막는 결함 0 | 신규 콘텐츠 중단 |

## 4. 출시 범위에서 빼는 것 (컷 리스트)

## 5. 출시 플랫폼
1순위 **itch.io 데스크톱 브라우저**(HTML5 업로드). 모바일 브라우저(iOS Safari·Android Chrome)는 터치로 한 판 완주·성능 확인 후 같은 페이지에서 지원. CrazyGames 등 포털은 공개 후 지표 보고 검토. **수익화는 4주 범위 밖.**
