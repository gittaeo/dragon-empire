# 풍향탑의 세 밤 — 초행 플레이 테스트 키트

목표: 처음 보는 사람이 안내만으로 낮에 준비하고 밤의 방어 목표를 이해하는지 확인한다. 3명 이상에게 **개별적으로**, 가능한 한 같은 빌드로 진행한다. 기록과 화면 공유는 참여자의 동의를 받고, 이름 대신 P1·P2·P3으로 적는다. 초행 3명은 시작점이며 이 결과만으로 난이도를 확정하지 않는다.

## 준비

- 테스트용 빌드 버전·커밋·실행 주소를 기록하고 작동을 미리 확인한다. 아직 공개나 업로드는 결정되지 않았다. 지인에게 전달하는 방식은 사용자가 정한다.
- 각자 새 판으로 시작하고, PC의 경우 키보드·마우스와 화면을 준비한다. 모바일은 실험 중이므로 기기·브라우저를 별도 기록하고 PC 결과와 합치지 않는다.
- 시계나 녹화 시간을 준비한다. 기록자는 좌측 표를 빈칸으로 두고 플레이어에게 정답을 미리 알려주지 않는다. 게임의 설명·도움말은 자유롭게 볼 수 있다.
- 테스트 전 아래 문장만 읽어준다: **“이 게임을 처음 실행했다고 생각하고 편하게 플레이해 주세요. 막히면 평소처럼 행동해 주세요. 저는 플레이 중에는 도와드리지 않고 관찰하겠습니다.”**

## 진행 규칙

1. 시작 버튼을 누른 순간부터 첫 낮 종료까지 측정한다. 관찰자는 조작법·방향·재료·작업대 위치를 설명하거나 유도하지 않는다. 놀람이나 불편함을 자발적으로 말하는 것은 듣고 기록한다.
2. 막혀서 도움을 요청해도 즉시 답을 알려주지 않는다. “평소라면 어떻게 하실 것 같나요?”라고 한 번 중립적으로 묻고, 계속 진행할 수 없으면 해당 지점·시간·도움 내용을 기록한 뒤 도움을 제공한다. **도움을 받은 뒤 성공은 독립 성공과 구분**한다.
3. 첫 밤 이후 승리·패배까지 진행한다. 원한다면 언제든 그만둘 수 있다. 실패 원인은 관찰 사실과 플레이어의 추측을 따로 기록한다. 이륙·재시작·보스 진입/격파 시각을 놓쳤으면 추정하지 말고 미측정으로 둔다.
4. 종료 후에만 아래 질문을 하고, 점수보다 본인의 말과 구체적인 장면을 받아 적는다. 테스트 중에 불편을 고쳐주거나 설정을 바꿨다면 버전·시점을 남긴다.

## 관찰 체크

- **첫 낮:** 재료 표식 발견, 획득 방법 이해, 작업대 발견·메뉴 열기, 목책 방벽/수리 차이 이해, 하나를 독립 제작했는지. 각 최초 시각과 낮 종료 시 잔여 재료를 적는다. 탑이 가득 찼을 때 수리 불가를 이해했는지도 본다.
- **첫 밤:** 자동 변신·이륙 인지, 공격 방향/표식/화살표 인지, 적과 탑을 구분하고 브레스로 요격했는지, 탑 HP 또는 용 HP가 왜 줄었는지 이해했는지 기록한다.
- **난이도·가독성:** 어디에서 헤맸는지, 용이나 UI가 대상을 가렸는지, 밤 실패의 직접 원인이 무엇인지(용 HP 0·탑 HP 0·중단·미확인), 프레임 저하·오류를 적는다.
- **보스:** 도달 여부, 보스가 실제 등장한 시각부터 승리/패배까지 걸린 시간, 탑 공격 예고와 주황 등불을 알아보고 요격했는지, 최종 탑 HP를 적는다. 보스 미도달 시 시간은 N/A.

## 종료 후 질문 5개

1. 첫 낮에 무엇을 해야 한다고 이해했나요? 어느 부분에서 가장 오래 헤맸나요?
2. 작업대에서 어떤 선택을 했고, 그 선택이 밤에 어떤 영향을 준다고 생각했나요?
3. 밤에 무엇을 지켜야 했고, 어느 방향으로 가야 하는지 어떻게 알았나요?
4. 가장 어려웠거나 불공평하게 느껴진 순간은 무엇이었나요? 이유는 무엇인가요?
5. 한 가지만 바꿀 수 있다면 무엇을 바꾸고 싶나요? 다시 플레이하고 싶은 정도를 1~5점으로 말해주세요.
