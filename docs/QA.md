## 3. 발견 이슈 (심각도: S1 치명 / S2 높음 / S3 중간 / S4 낮음)

### S1
- **B-12 모바일 조작 없음.** game.js:35는 keydown/mousedown/mousemove만 처리하고 touch/pointer 이벤트가 없습니다. index.html:1 viewport에 `user-scalable=no`가 없고 style.css에 `touch-action:none`도 없습니다. → 타깃 플랫폼(안드로이드)에서는 시작 버튼만 누를 수 있고 비행/공격이 불가능할 것으로 판단합니다. (TASKS T4)
- **B-01 드로우콜 예산 초과(추정).** `environment.js`(인스턴싱 지형, 나무 2드로우)는 **어디서도 import되지 않습니다**(game.js에 'environment' 문자열 0건). 대신 game.js:9–13이 개별 메시를 만듭니다: 산 원뿔 최대 90, 나무 줄기+잎 최대 360(잎마다 `mat()`로 새 재질 생성, 12행), 반투명 구름 구 140(재질 140개, 13행), 드래곤 21마리 × 11메시 = 231. **정적 추정 최대 약 800 드로우콜**로 COLLAB §4 예산 150의 약 5배입니다(실측 아님). 반투명 구름 140개는 모바일 오버드로 위험도 있습니다. (T1, T5)

### S2
- **B-02 카메라/플레이어 지형 충돌 없음.** game.js:38 카메라 위치 = `player - 22·viewDir + 7·viewUp`이고 지형 검사가 없습니다. 플레이어 최저 고도 y=8(37행 clamp), 지면 y=-4(9행)일 때 피치가 약 0.85rad(49°) 이상이면 계산상 카메라 y가 지면 아래로 내려갑니다(pitch=1.0 → 약 -6.7). 산 원뿔(11행, 높이 45–185)은 플레이어와 카메라 모두 통과합니다. (T3)
- **B-03 조준점 ≠ 탄도.** 탄은 `player.position + 4·aim`에서 `aim` 방향으로 나갑니다(37행). 십자선은 화면 중앙(=카메라에서 `player+14·dir+2·up`을 향하는 광선, 38행)입니다. 두 선은 Lv1 기준 플레이어 앞 약 28m에서만 만납니다. 250m에서는 탄이 십자선 지점보다 약 31m 위를 지나는 것으로 계산됩니다. 카메라 거리가 레벨에 따라 바뀌므로(38행 `22*(1+(level-1)*.12)`) 오차도 레벨마다 달라집니다. (T3-4)
- **B-04 적이 뒤돌아 있음.** 37행 `e.lookAt(player.position)`: three.js의 Object3D.lookAt은 +Z를 대상에 향하게 합니다. 도형 드래곤의 머리는 -Z(14행 head z=-2)이므로 적의 **꼬리가 플레이어를 향합니다**. (T3-5)
- **B-07 진화 구조가 기획과 불일치.** 28행 `level=min(5,1+floor(xp/3))`, 32행은 Lv3에서 분기하고 Lv5에서 종료합니다. 스케일은 최대 1.88배(28행)입니다. SKILLS.md는 4단계, Lv10/20/30, 스케일 1.0/1.8/3.0/4.5, 분기는 2단계 진입 시입니다. 외형 교체는 색 변경뿐(30행)이라 GLB 교체 구조가 없습니다. (T6)
- **B-18 적이 위협이 되지 않음.** 37행: 적은 거리 25 초과일 때만 접근하고, 피해는 거리 23 미만일 때만 줍니다. 플레이어가 직접 부딪히지 않으면 피해를 받지 않습니다. 원거리 공격도 없습니다. DODGE 스킬의 존재 의미가 없습니다. (T7-4)

### S3
- **B-05 피치 무제한 + 뒤집힘.** 35행이 pitch를 ±π로 감고 `cos(pitch)<0`일 때 yaw 입력 부호를 뒤집습니다. 38행 `camera.up=viewUp`이 뒤집혀 화면이 거꾸로 됩니다. 모바일 드래그에서는 방향 감각을 잃기 쉽습니다. (T3-1)
- **B-06 프레임레이트 의존 보간.** 38행 `camera.position.lerp(..., .12)`, 37행 `rotation.z lerp .08`이 dt와 무관합니다. 30fps 기기에서는 카메라가 60fps보다 2배 느리게 따라옵니다. (T3-3)
- **B-08 적 20마리 고정, 리스폰 없음.** 16행. 현재 Lv5(12킬)에는 충분하지만 Lv30 체계로 바꾸면 진행할 수 없게 됩니다. (T6-6)
- **B-09 결과 화면에 진화 경로 없음.** 31행 `finish()`는 처치 수와 보상만 표시하고 `path`·단계·시간을 표시하지 않습니다. (T8)
- **B-10 재시작 = `location.reload()`.** 30행. 웹에서는 동작하지만 GLB를 도입하면 매번 다시 로드됩니다. Capacitor에서는 흰 화면이 깜빡일 위험이 있습니다. (T8-5)
- **B-11 localStorage 예외 처리 없음.** 27행은 **모듈 최상위**에서 `localStorage.getItem`을 호출합니다. 저장소가 차단된 환경(일부 웹뷰/샌드박스 iframe/쿠키 차단)에서는 SecurityError가 나서 **모듈 전체가 실행되지 않습니다**(게임 시작 불가). 31행 setItem도 같습니다. (T8-1)
- **B-13 외부 폰트 의존.** style.css:1 Google Fonts `@import`. 오프라인/앱 환경에서 폰트 로드가 실패하거나 지연될 수 있습니다(게임 정지는 아님). (T10-1)
- **B-15 매 프레임 객체 할당.** 22행 `spark()`마다 `new T.Color`, 37행 적 루프마다 `new T.Vector3()`, 탄 꼬리마다 `new T.Vector3` 2개. 모바일에서 GC 끊김 위험이 있습니다. (T5-7)
- **B-19 서버.** server.cjs:1이 `127.0.0.1`에만 바인딩해서 휴대폰 실기기 테스트가 불가능합니다. `.json/.glb/.png` MIME이 없어 `application/octet-stream`으로 응답합니다(fetch/GLTFLoader는 대부분 동작하지만 확인 필요). (T1-5)
- **B-20 GLB 로더 준비 안 됨.** index.html에 importmap이 없습니다. `vendor/package/examples/jsm/loaders/GLTFLoader.js`는 존재하지만 내부에서 `'three'`를 bare import하므로 importmap 없이 game.js에서 import하면 실패합니다(검토 HTML 2개는 importmap이 있음). manifest 로더와 폴백이 없습니다. (T1-1, T2)

### S4
- **B-14** 4행 `shadowMap.enabled=true`인데 castShadow 설정이 없어 그림자가 나오지 않습니다(의도 불명). 36행 resize에서 pixelRatio를 다시 설정하지 않습니다.
- **B-16** 37행 탄 명중 반경이 고정 5이고 적 스케일과 무관합니다. 점 검사 방식이라 저fps + 고속탄에서 터널링 가능성이 있습니다(현재 수치로는 dt≤0.05, 이동 6 < 지름 10이라 낮음).
- **B-17** 37행 `keys.ShiftLeft`만 확인합니다. 오른쪽 Shift는 무시됩니다.
- **B-21** 37행 플레이어 회전은 이동/발사 키 입력 중에만 카메라 방향으로 갱신됩니다. 시점만 돌리면 드래그를 놓은 뒤에도 드래곤이 예전 방향을 봅니다(의도인지 확인 필요).
- **B-22** 게임 종료 후 루프가 탄 갱신을 멈춰 37행 bolts가 결과 화면 뒤에 정지한 채 남습니다.
- **B-23** 21행 파티클 `gl_PointSize` 상한 120. 일부 모바일 GPU는 최대 포인트 크기가 64라 큰 불꽃이 잘릴 수 있습니다.
- **B-24** `#objective`(index.html) 문구가 진행에 따라 갱신되지 않습니다.
- **B-25** 검토용 HTML 2개(`dragon-review.html`, `dragon-flight-review.html`)의 `<title>`이 같고, 14.9MB `concepts/realistic-dragon-review.glb`(COLLAB상 미승인, 예산 5MB 초과)를 로드합니다. 게임 본편과는 무관하지만 배포 빌드에서 제외해야 합니다.
- **B-26** README.md가 "PC 키보드와 마우스용", "Lv.3 진화/Lv.5 황제"로 설명합니다. 기획 변경 후 갱신이 필요합니다.

## 4. 사람이 확인해야 할 테스트 체크리스트 (전부 미실행)

- [ ] [PC] `node server.cjs` → 접속 시 콘솔 에러 0개, 시작 화면 표시

### B. 비행·카메라 (PC)

- [ ] 피치를 끝까지 돌렸을 때 화면이 뒤집히지 않는가(B-05)

- [ ] 창 크기 변경, 창 포커스 이탈(blur) 시 키가 눌린 채 남지 않는가

### C. 전투
