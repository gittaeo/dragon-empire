# 드래곤 엠파이어 — VFX 사양 v0.1
작성: 3D 아트/VFX 리드 (Claude) · 2026-11-20 · 기준: docs/SKILLS.md v0.1 · 상태: 초안(Codex 플레이테스트로 조정)

비주얼 톤: 시네마틱 스타일라이즈드. 코어는 흰색에 가까운 고휘도, 가장자리로 갈수록 채도 높은 오렌지→어두운 적색. 모든 이펙트는 Additive 블렌딩 + `UnrealBloomPass`(threshold 0.85) 전제, "블룸 강도"는 해당 머티리얼의 emissiveIntensity / 색 배수.

## 모바일 성능 예산 (중급 안드로이드, 60fps 목표 / 최소 30fps)
- 화면 동시 파티클 총합 ≤ 1,500 (저사양 옵션 ≤ 600, 모든 수치 ×0.4).
- 이펙트 드로우콜 ≤ 12: 스킬별 `InstancedMesh` 또는 `Points` 1개, 텍스처는 512² 아틀라스 1장(불꽃/연기/스파크/링 4칸).
- 투명 오버드로: 화면 면적 대비 큰 쿼드(메테오 폭발, 방패, 궁극기)는 동시 2개 이하.
- 블룸: 해상도 ½ 렌더, strength 0.8 기본, 저사양은 블룸 끄고 emissive만.
- 동적 라이트: 동시 PointLight ≤ 2 (연사·메테오용 공유 풀, distance 12).
- 파티클은 오브젝트 풀링, 런타임 new 금지.
