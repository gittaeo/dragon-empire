# 디자인 브리프 — 풍향탑의 세 밤 v2 (디펜스 재설계)

2026-11-22 · Claude(리드) 작성 · 팀 토론용 공통 입력. **모든 역할 에이전트와 Codex는 이 문서에서 출발한다.**

## 0. 왜 다시 설계하나 (사용자 피드백, 원문 요지)
- "저렇게 집 짓고 하는 거 좋아." → 건설 방향 자체는 맞다.
- "망루는 적 공격하는 거인 거 알겠어. 다른 것들은? 특히 **집은 지어서 뭐가 좋은데**. 병사가 나오게 하든지 뭔가 **의미가 있어야** 하잖아."
- "지금 재미가 너무 없어." / "영상 보고 참고하라고 다 떠먹여 줬는데 결과가 이것뿐이야?"
- "디렉터·디자인팀 등 AI 에이전트 만들어서 Codex와 충분히 대화하고 진행하라."
- 앞선 피드백: 낮에 할 게 없다 → 제한시간 제거함. 기지가 그늘 → 양지 이동함. 월드가 아니라 개인 디펜스 → 공간 축소함. 걷기 리깅 → 재리깅 미리보기.
- 목표: **1인 개발, 약 1개월 안에 itch.io 출시** 가능한 범위. 기존 에셋 재사용.

## 1. 참고 자료에서 배운 것
### 영상 A — "스팀 타워디펜스 갓겜 12선" (자막 전수 분석)
- Kingdom Rush: 정해진 길목의 타워 자리, 4계열 타워 → 2갈래 특성화. 병영 타워의 병사가 길을 막고 몸싸움 → 배치만 잘해도 전선이 단단. 영웅을 직접 움직임.
- Thronefall: 낮에 집·금광·성벽·탑을 세우고, **살아남은 건물이 아침마다 골드**를 번다. 밤에 왕이 직접 싸움. 성 중앙이 무너지면 끝.
- Kingdom Two Crowns: 코인으로 성벽·탑을 올림. 낮에 백성 모으고 농장·방어탑, 밤엔 괴물. 왕국을 키울수록 궁수·기사 등 새 유닛.
- Wall World: 채굴로 자원 → 자동 포탑·수리 스테이션.
- Riftbreaker: 기지 건설 + 외벽·방어탑 + 메카로 직접 전투.
- Bad North: 병사 부대를 섬 곳곳으로 옮겨가며 막음, 지형 활용.
- 노움들: 매 턴 방어시설·작물 배치, 밤마다 침입, 경로가 판마다 달라 진영을 새로 짬.

### 영상 B — Thronefall 실플레이 43분 (자막 전수 분석, 핵심)
- 왕(말 탄 주인공)은 이동만 해도 **자동으로 활을 쏨**, 스페이스로 근접/특수. 직접 몸빵하며 전선을 받친다.
- 낮: 맵의 **건설 자리**에 코인을 넣어 짓기/업그레이드 — 집(인구·수입), 금광(수입), **농장(수입 크지만 적에게 취약)**, 망루, 성벽·**성문**, **막사(병사 생성 — 창병·궁수·기사 등 선택)**. 짓는 즉시 효과가 보임.
- 밤 시작은 플레이어가 스페이스로 선택. **다음 밤 적이 어느 방향에서 몇이 오는지 미리 볼 수 있음(Alt).** 미니맵으로 한눈에.
- 병사는 **배치 명령 / 자유 행동** 전환, 집합·돌격 명령. 병사가 죽어도 다음 날 부활.
- **건물은 밤에 부서지고, 아침에 자동 재건**(매 턴). 살아남은 건물이 수입.
- 레벨 사이 **영구 업그레이드 선택**(로열 트레이닝: 체력·피해 +, 빌더스 길드: 집 자동 업그레이드 등). 무기 선택(활/창/철퇴) — 플레이 스타일이 바뀜.
- 적: 기본·굴러오는 적·**날아오는 적(화살로만 막음)**·뚱땡이(탱커)·투석기(공성). 종류마다 대응 수단이 다름 → 건물 선택에 의미.
- 재미 포인트(시청자 반응): "돈을 많이 모으는 게 중요", "깨면서 배운다", "전쟁 보는 것 같다", "밀려도 괜찮다, 병력은 계속 나오고 성벽이 굳건", "다 막았다!" 순간. 3시간 몰입.

## 2. 현재 게임 상태 (코드 기준, 81066f7 + 4c9f172)
- 엔진: three.js 웹. 파일: `nights.js`(규칙), `base.js`(건설 자리·망루 사격·수입), `fortify.js`(목책·연기·비계·재료 운반 연출), `ground.js`(인간형·지면), `game.js`(용 비행·전투·적·보스).
- 루프: 낮(인간형 폴리모프, 제한시간 없음) 재료 줍기(가지4·돌3·파편2/일) → 탑 둘레 **건설 자리 11곳**(목책 4방향, 망루 4, 집 3)에서 E로 짓기·2단계 강화 → 풍향탑 E 메뉴 '밤을 맞이한다'(수리도 여기) → 용으로 변신·이륙 → 밤 웨이브(예보 2방향) → 아침 수입 → 3밤 후 대관(엠페러 진화) → 보스 루세르나(탑 공격 등불 요격).
- 건물 현황: 목책(그 방향 습격 5/9회 차단, 아침 복구), 망루(자동 사격 14/24 피해), **집(아침 재료 수입만 → 의미 약함: 사용자 지적)**.
- 적: **모두 공중**(등불 나방 moth = 탑 돌진형 raider, 등불 기수 rider = 사냥꾼, 용을 노림). 승인 에셋에 **지상형 '사슬 기사' chain_knight GLB 존재**(현재 세 밤 미사용). 보스 boss_lucerna.
- 용: 4단계 진화 모델(해츨링→드레이크→와이번→엠페러), 브레스·스킬(Q/E/R), 밤마다 진화.
- 기지 반경: 인간형 이동 탑 80m, 목책 반경 34m, 적 출현 320m.
- 테스트: Codex 소유(tests/*), 단위 46 + Playwright 회귀.

## 3. 제약
- 1인·1개월. 새 3D 에셋은 사용자 승인 필요(Higgsfield 크레딧). 절차 지오메트리(코드로 만든 건물·병사)는 자유.
- 성능: 웹·저사양 고려(유닛 수 상한).
- 기존 조작(우클릭 드래그 무제한 시점, 용 비행)은 유지.

## 4. 이번 토론에서 답해야 할 질문
1. **모든 건물이 분명한 의미**를 갖게: 집·목책·망루 외에 무엇이 필요한가(막사/병사, 농장/광산, 성문 등)? 집은 무엇을 하나(인구→병사? 수입?).
2. 적이 전부 공중이면 목책·병사가 왜 필요한가? **지상 적(사슬 기사 등)을 넣을지**, 공중/지상 역할 분담.
3. 용(플레이어)의 역할: 직접 싸움과 자동 방어의 비중. "손 놓으면 이기는" 상태 방지.
4. 낮의 할 일: 자원 수급 구조(채집/수입/처치 보상), 선택의 긴장(무엇을 먼저 지을지).
5. 3밤 진행 곡선: 밤별 적 구성·신규 위협·신규 건물 해금, 보스까지.
6. 한 판 밖 진행(영구 업그레이드·재도전 동기)이 1개월 범위에 필요한가.
7. 1개월 안 구현 가능한 **MVP 범위와 자르기 기준**.
