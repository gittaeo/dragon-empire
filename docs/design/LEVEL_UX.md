### 1.4 길·성문·목책 라인

- **길 4개**: 정방위, 폭 6m, 광장 가장자리 r12 → 경계 r80 → (밤에만) r320 출현점까지 흙길 텍스처/색 띠로 연장. 지상 적(사슬 기사 등)은 **길만** 따라온다 → 플레이어가 "어디로 올지" 바닥만 봐도 안다.
- **성문**: 목책 호 중앙(문 폭 5m). 낮엔 열림(주민·플레이어 통행), 해질녘 연출에서 **닫힌다**. 지상 적은 성문을 때려야 들어온다(성문 HP는 전투 역할 결정 — §7).
- **목책 라인 r34**: 현 구현 그대로 방향당 82.8° 호. 대각 틈 4.3m는 모서리 망루 자리. 망루 미건설 틈은 낮에 **붉은 점선 데칼**로 "열린 틈" 표시.
- **공중 적**은 길과 무관하게 직선 비행(현 `raidStep`). 목책의 "막는 횟수"는 공중 적에게도 유지(현 규칙) — 시각적으로는 목책 위로 솟는 "바람막이 장막"이 막는 것으로 연출(전투 역할과 조율).

## 2. 건설 UX

### 2.1 다가갈 때 — 3단 거리 반응

| 거리 | 보이는 것 |
|---|---|
| 40m 이내(시야) | 자리 깃발 색 + 바닥 원 상태: **금색 맥동** = 지금 지을 수 있음 / **흰 점선** = 재료 부족 / **회색+자물쇠** = 아직 잠김 / 원 없음 = 최고 단계 |
| 7m 이내 | 월드 공간 **정보 카드**(자리 위 2.5m, 가장 가까운 1개만) — 아래 형식 |
| 2.8m 이내 | 카드 하단 행동 줄 활성: `E 길게 0.5초 — 짓기` + 자리에 **금빛 홀로그램(다음 단계 모델 반투명)** |

정보 카드 형식(최대 4줄, 아이콘 위주):
```
┌──────────────────────────────┐
│ 망루 · 북동   Lv0 → Lv1        │  ← 이름 + 단계
│ 🪵 2/2  🪨 1/1  ✦ 0/1           │  ← 보유/필요, 부족분만 붉게
│ 밤에 등불 자동 사격 · 사거리 120 │  ← 효과 1줄(숫자 1개 이상)
│ 다음: Lv2 피해 14→24            │  ← 다음 단계 미리보기(회색)
└──────────────────────────────┘
```
- 망루는 카드가 뜨는 동안 바닥에 **사거리 원(파란 데칼)**을 1.5초 그려준다(120m는 들판 경계를 넘음 → "북·동 두 방향을 다 덮는다"가 보임).
- 성문은 해당 방향 **목책 호 전체 윤곽**을 홀로그램으로, 집은 **주민 경로 점선**(집 → 가장 가까운 채집 구역)을 보여준다.

### 2.2 지을 수 없을 때 — 이유 우선순위(하나만 표시)

| 순위 | 조건 | 카드 행동 줄 문구 | 추가 안내 |
|---|---|---|---|
| 1 | 밤/해질녘 | 밤에는 지을 수 없습니다 | — |
| 2 | 잠김 | 둘째 날에 열립니다 | 자물쇠 아이콘 |
| 3 | 선행 필요 | 집이 먼저 필요합니다 | 가장 가까운 빈 집 자리에 금빛 점 3개 |
| 4 | 재료 부족 | 돌 1 부족 | **부족 재료 구역 쪽으로 바닥 화살표 3초** (돌 → 채석장 NE) |
| 5 | 최고 단계 | 최고 단계 | 원 숨김 |

현재처럼 실패 시 배너 1.8초 대신 **카드 자체에** 남겨 둔다(배너는 다른 정보를 덮음).

### 2.3 짓는 순간 (총 1.4초, 연속 건설 가능)

1. E 길게 0.5초: 재료 아이콘이 플레이어 손에서 자리로 날아감(현 `fort.carry`, 시간 0.6~1.6s → **0.6s 고정**으로 단축).
2. 착지 0.1초: 비계·먼지(`burst`) + 쿵 소리.
3. 솟음 0.8초: 현 `scale.y` 이징 그대로.
4. **카메라 포커스는 종류별 첫 건설에만**(현 `ctx.focus` 2.2초 매번 → 반복 시 조작 끊김). 두 번째부터는 카메라 고정.
5. 완성 배너 대신 자리 위 **떠오르는 숫자**: `+5 막음`, `사거리 120`, `주민 +2`.

### 2.4 지은 뒤 효과가 "보이는" 방식

| 건물 | 낮에 보이는 것 | 밤에 보이는 것 |
|---|---|---|
| 성문+목책 | 문이 열린 채 서 있고, 문 옆 등불 점등. 호 위 말뚝 수 = 막는 횟수(현 세그먼트 표시 유지) | 해질녘 문이 닫힘. 막을 때마다 말뚝 1개가 부서져 날아감 |
| 망루 | 꼭대기 눈(현 `eye`)이 천천히 회전. 처음 지었을 때 **허수아비 과녁에 시범 사격 1발** | 사격 궤적(현), 눈 밝기 |
| 집 | **주민 2명(Lv2: 3명)**이 문을 열고 나와 가장 가까운 채집 구역으로 걸어가 재료를 등에 지고 돌아옴(루프 약 60초). 굴뚝 연기 | 창 불빛. 막사가 있으면 주민이 창을 들고 **성문 뒤로 집결** |
| 막사 | 깃발 + 훈련 중인 병사 2명(제자리 찌르기) | 병사가 배정된 성문 앞으로 행군 → 지상 적과 몸싸움 |
| 농장 | 밭에 싹 → 낮마다 자람(3단계 모형). 주민 1명이 김매기 | 적이 지나가면 밭이 짓밟힘(다음 아침 정산에 "농장 피해") |

- 주민·병사는 절차 지오메트리 인형(현 `person()` 재사용). **상한: 주민 8, 병사 12**(저사양).
- "집은 의미가 없다"에 대한 UX 답: 무엇을 하든 **집에서 사람이 나와 움직인다**. 수입은 주민이 들고 온 재료가 아침 정산에서 "주민이 모은 것"으로 다시 날아오는 형태로 표시.

## 3. 예보·밤 HUD·미니맵

### 3.1 예보 UI (낮 내내 확인 가능)

- **상단 우측 상시 칩**(낮): `오늘 밤 ▲북 12  ▶동 ⚔4` — 방향 화살표 + 수 + 종류 아이콘(나방 ●, 기수 ◆, 사슬기사 ⚔, 보스 ♛). 현 목표 패널(우상단) 첫 줄을 이 칩으로 교체.
- **Tab(PC) / 예보 버튼(터치) 길게**: 화면 중앙 반투명 **방위 나침반** 오버레이(260px). 탑 중심 4방향 쐐기에 적 수·종류·습격 순서(1→2→3 숫자), 지은 성문/망루가 그 쐐기를 덮는지 초록/붉은 테두리. 놓으면 닫힘. 예보 석판 E도 같은 화면.

- 데이터: `buildWaves()` 결과를 방향별 합산(count·hunters·종류). 낮 시작 시 이미 확정되므로 숨길 이유 없음. 단, **습격 순서와 rush 수정자는 "?"로 일부 숨김** 여부는 전투 역할과 조율.

### 3.2 밤 HUD (화면 중앙 60%는 비운다)

- 현 `#raidmarks` 8개 유지. 지상 적 표식은 ◆(마름모)로 구분.

### 3.3 미니맵 — **필요. 단 "레이더" 최소형**

- 근거: 용은 시점 무제한 회전 + 4방향 + (지상 적 도입 시) 땅/하늘 두 층. 가장자리 화살표만으로는 "탑과 적의 상대 위치"를 못 읽는다(플레이테스트 질문 3번 리스크).
- 사양: 우상단 원형 132px(모바일 96px), **북쪽 고정**, 반경 350m 표시. 탑(금 점) · 목책 원 r34(방향별 남은 호만 밝게) · 적(붉은 점 / 지상 ◆ / 보스 주황 큰 점) · 용(흰 화살표, 시선 방향 부채꼴). 2D canvas, 10Hz 갱신.
- 낮: 같은 레이더를 반경 80m로 확대해 **건설 자리 상태 점**(금=지을 수 있음, 흰=부족, 회=잠김, 채움=완료) + 채집 노드 + 플레이어. → "어디 가서 뭘 할지"를 레이더 하나로.

### 4.1 첫 낮 — 행동으로만 진행 (텍스트는 최대 3장면, 각 1줄)

| # | 플레이어 행동 | 세계가 하는 일(안내) | 화면 텍스트 |

| 0 | (착륙·변신 직후 자동) | 2.5초 설정 샷: 카메라가 착륙장 → 탑 → **오늘 밤 방향 하늘 기둥**을 훑고 돌아옴 | `오늘 밤 · 북쪽` (나침반 칩이 우상단으로 날아가 붙음) |

| 5 | 북문·망루 등 1~2개 더 짓는다 | 짓기 2회 이상 또는 재료 소진 시, 반딧불 길이 **풍향탑**으로 | `준비되면 풍향탑에서 E — 밤을 맞이한다` |

- 반딧불 길은 첫 낮 전용, 2낮부터는 레이더 금색 점이 대신한다.

## 5. 낮↔밤 전환과 아침 정산

### 5.1 해질녘 (탑 E → 이륙까지 6초, 스킵 불가·조작 불가 구간 최소화)

| 시각 | 연출 |
|---|---|
| 0.0s | 탑 등불 점화음. 시간 12시 → 19시를 **2.5초에 걸쳐 보간**(현 `setHour(19)` 즉시 → 보간) |
| 0.5s | 주민이 집으로 뛰어 들어감, 창문 점등. 병사가 성문으로 행군 |
| 1.5s | 성문 4개가 차례로 닫힘(북→동→남→서, 0.3s 간격), 쿵 |
| 2.5s | 카메라 상공으로 빠지며 변신(현 `toDragon`) |
| 4.0s | 이륙 → 예보 방향 하늘 기둥이 진해짐 → `1번째 밤` 배너 |
| 6.0s | 첫 습격 시작(현 `waveT 1.5`) |

### 5.2 새벽 — "하루를 버텼다"

1. 마지막 적 처치 순간 **0.6초 슬로모션** + 저음 종소리. 배너 `새벽이 온다`.
2. 3초 동안 19→6.5시 일출 보간, 카메라는 탑 상공 60m 원형 선회(기지 전체가 해 뜨는 빛에 보임).
3. 진화 연출(현 `ctx.morning`).
4. **아침 정산 카드**(중앙, 최대 8초, 아무 키로 스킵, 스킵해도 수치는 레이더/가방에 반영):

```
        ── 첫째 밤을 버텼다 ──        (밤 수 pip ●○○)
  풍향탑   80 → 64        처치  31   목책이 막음  7
  ─────────────────────────────────────
  수입      집 ×2  🪵+2 🪨+2   (집에서 아이콘이 가방으로 날아옴)
            처치 보상  ✦+3
            농장      —
  피해      남쪽 목책 무너짐 → 아침에 다시 섬(무료)
            집(240°) 불탐   → 재건 🪵1        [기지에서 확인]
  ─────────────────────────────────────
  오늘 밤 예보  ▲북 14  ◀서 ⚔6
```
- 숫자는 0에서 **카운트업**(행마다 0.3초), 수입 아이콘은 실제 건물 위치에서 화면 가방 칸으로 날아감 → "내가 지은 게 벌었다"가 공간적으로 연결.
- 피해 줄은 붉게, 재건 비용은 경제 역할 결정. 파괴된 건물은 낮에 **검게 그을린 잔해 + 붉은 원**으로 남아 레이더에도 표시.
- 마지막 줄에 **다음 밤 예보** → 정산이 곧 다음 계획의 시작.
- 현 "착륙하세요(금빛 기둥)" 대기 단계는 정산 뒤 **자동 활공 착륙**(착륙장으로 4초) 제안. 수동 착륙을 원하면 이동 입력 시 즉시 해제.

## 7. 쟁점 (다른 역할과 조율 필요)

### 시스템·경제
1. **집의 정체**: UX는 "주민이 나와 움직인다"만 요구. 주민 = 수입 운반자인지, 막사의 병사 재료(인구)인지, 둘 다인지 경제가 확정해야 한다. 내 제안: 집 Lv1 주민 2 = 아침 수입 + 막사 있으면 밤에 창병으로 전환.
2. **자원 구역·노드 수**: 4구역 고정 배치 + 자동 줍기 시, 낮마다 노드 수(제안 가지6·돌4·파편2)와 리젠 여부. 노드가 너무 많으면 순회가 지루, 적으면 짓기 선택이 1개뿐.
3. **비용 표시 단위**: 재료 3종 유지 vs 단일 화폐(코인) 통합. 단일 화폐면 카드·정산이 훨씬 읽기 쉬움(Thronefall). 3종 유지면 아이콘 색 고정 필요.
4. **파괴·재건 비용**: 무료 자동 재건(Thronefall) vs 유료. 정산 카드의 "피해" 줄 형식이 이에 따라 바뀜.
5. **해금 일정**(1낮 성문4·망루4·집2 / 2낮 집+2·막사·농장·Lv2 / 3낮 보스 대비)과 비용 곡선 일치 여부.

### 전투·웨이브
6. **지상 적 도입**: 길 4개·성문·병사·농장 피해의 존재 이유가 지상 적이다. 도입하지 않으면 길·성문은 장식이고 레이아웃은 r25 압축형으로 돌아가야 한다. → **가장 큰 쟁점**.
7. 목책 "막는 횟수" 모델(현)과 성문 HP 모델(지상 적용)의 병존 여부. UX 표시(pip vs 바)가 달라짐.
8. **첫 밤 1방향 고정** 요청(온보딩 명료성) — 현 `forecast`는 항상 2방향.
9. 예보 공개 범위: 방향·수·종류는 전부 공개, 습격 순서와 rush는 숨길지.
10. 성능 상한: 주민 8 + 병사 12 + 적 동시 최대치 합계를 전투 쪽 상한과 합산해 확정.
11. 망루 사거리 120m는 반경 80m 기지보다 큼 → 위치 선택이 의미 없어짐. 사거리 60~70m로 줄여 "모서리 망루는 인접 두 방향만" 되게 할지.

### 스토리
12. 세라의 역할: 매 낮 조언 1줄 + 정산 화자 + 2·3낮 신규 요소 소개. 대사량은 낮당 최대 2줄.
13. 주민의 정체(풍향탑 마을 피난민?)와 이름 유무, 집이 불탔을 때 감정선(사망 없음 권장 — 3밤 짧은 판에서 영구 손실은 좌절만 남김).
14. "예보 석판" 설정(누가 바람을 읽는가) — 현 작업대 자리를 재활용하는 명분.

### 기술(Codex)
15. 착륙장 r38 → r46 이동, 이동 한계 r80 경계의 시각화(선돌), 작업대 오브젝트 제거·대체, `nearest()` 2.8m 외에 7m 카드용 "가장 가까운 자리" 질의 추가, 자동 줍기 판정. 회귀 테스트 영향 범위 확인 필요.

## 8. 이 설계가 만드는 순간 (요약)

- 착륙해 남문으로 걸어 들어가며 **오늘 밤 북쪽**을 하늘 기둥으로 본다 → "저쪽을 막아야 해".
- 문을 지으면 호가 솟아 원이 닫혀 간다 → "내 성이 생긴다".
- 집 문이 열리고 주민 둘이 숲으로 걸어간다 → "집이 살아 있다".
- 해질녘 성문이 하나씩 닫히고 창문에 불이 켜진다 → 긴장 직전의 고요.
- 새벽 슬로모션, 일출 선회, 건물에서 날아오는 수입 숫자 → "버텼다, 그리고 벌었다".
