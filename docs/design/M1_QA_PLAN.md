# 디펜스 v2 M1 — QA 준비와 훅 계약 제안

2026-11-22 · 결정서 `DEFENSE_V2_DECISION.md` §4 기준. Claude 구현 중: 아래는 요구 계약이지 현재 구현·통과 주장 아님. 기존 게임 모드와 탐험 저장을 변경하지 않는다.

## 검증 항목과 필요한 관찰값

| 항목 | 검증 시나리오 | 최소 관찰/행동 계약 |
|---|---|---|
| 비용 | 충분: 한 번만 차감·완성. 부족: 가방/레벨/유닛 변함없음. 연속 입력: 중복 차감 없음 | `base.pads`의 id/type/level/busy/pos, `ground.world.bag`, 실제 E 상호작용 |
| 집·막사 | 시작 집 주민 2, 집별 주민 합과 막사 정원; 병사 = min(주민, 정원). 막사 없음 0·인원 초과·상한 6 | `state.residents`, `state.soldiers`의 숫자 의미와 활성 병사 엔티티 ID 목록 |
| 부상·복귀 | HP 0 후 밤에 복귀하지 않고 다음 낮 한 번만 복귀. 여러 프레임·재시작 중복 없음 | 실제 병사 HP/상태와 안정적 ID, 관측 가능한 부상 유발 경로 또는 별도 격리된 디버그 훅 |
| 성문 | HP 최대→양수→0, HP 음수로 내려가지 않음, 0에서 더 맞아도 중복 붕괴 없음, 다음 낮 최대 복구 | `state.gates[dir]`의 hp/max 및 문 단계, 실제 기사 공격 또는 테스트 전용 피해 훅 |
| 대공 분리 | 나방이 성문을 통과해 탑 피해; 성문 HP는 그대로. 기사는 병사→성문→탑 우선 | 적 종류·고도·목표 상태 및 실제 공격 이벤트. 테스트 위치 조정 시 명시 |
| 경로 | 4방향 각 9~150m 샘플(1m 간격), 경사 >25°·수면 아래 보고. **실제** 기사 위치와 지형 오차는 별도 관측 | `nights.towerPos`, `terrain.heightAt`, waterLevel; 실제 경로 좌표·기사 종류·발 기준 y/모델 오프셋 |
| 예보 | seed별 예보의 방향·종류 합계가 실제 스폰과 일치. 상한 대기 중 조기 종료·누락 없음 | 고정 웨이브 계획, 예보 집계와 spawn 이벤트 또는 단조 카운터. 같은 타입의 기존 적/보스 소환과 구분 |
| 동시 승패 | 같은 프레임 탑 HP 0 및 보스 사망에서 패배 | 동일 프레임 입력을 보장하는 격리 테스트 훅이나 순수 상태 전이 함수 |
| 브라우저 | 집 건설→주민 표시→막사→병사 집결→기사 교전→성문 피격→다음 낮 복구·병사 귀환 | HUD·씬에서 식별 가능한 객체/상태, 캡처. 위치 이동은 표시하고 화면 가독성은 별도 평가 |
| 입력 봇 10 seed | 표준 빌드 막사+성문A 후 실제 시간/합성 조작, 1밤 승리·병사 처치 비율·최저 탑 HP·용 사망 기록 | 야간에는 상태 읽기+합성 입력만. 낮 위치 이동 허용 여부·조준 프로파일을 결과에 명시. 병사 처치 출처 집계 미구현이면 비율은 미검증 |
| 성능·사람 | 최악 장면 실제 60초 p95 ≤33.3ms, 1명 이상 설명 없이 집→병사 이해 | 기기·해상도·브라우저·장면·샘플 수, 사람 관찰 기록. 자동 측정/봇으로 대체 불가 |

훅은 `window.__game.nights` 아래에서 **읽기 전용 관찰값 우선**. 강제 피해/웨이브 제어는 디버그 전용으로 구분하고, 봇 밸런스 집계에서는 사용하지 않는다. `state.soldiers`가 수치인지 배열인지, 사망 병사와 풀링 객체의 생명주기, gate 파괴 시 HP 바와 모델에 필요한 값, spawn 큐/카운터, 공격 및 사망 출처 계약을 확정해 AGENT_BOARD에 알려 달라. 훅이 없으면 테스트를 억지로 통과 처리하지 않는다.

## 사전 지형 샘플 (M1 구현 전, 현 서버)

`tests/defense-m1-terrain.cjs`: 풍향탑 기준 정북/동/남/서 중심선 9~150m, 1m 간격 142점/방향. 25° 초과 구간 각 0; 최대 기울기 북 9.05°, 동 18.63°, 남 9.58°, 서 18.85°. **동쪽 27점은 원 지형 높이가 수면 아래**. 이 측정은 제안 직선 중심선이며 장애물, 실제 경로·차선, 1m 사이의 급경사, 기사 발이 땅에 닿는지는 검증하지 않는다. 게임은 수면으로 높이를 보정하므로 물 위 이동/길이 물에 잠기는 가시성 위험을 실제 장면에서 확인하고 우회 경로·교량·해당 지형 조정 중 하나를 결정해야 한다.

## 인수 조건 해석

10 seed 중 9회, 병사 처치 ≥10%, p95, 사람 1명의 이해는 각각 별도 결과로 보고한다. `nights-play`의 강제 처치/시간 단축은 기능 회귀일 뿐 밸런스 합격 근거가 아니다. 완성 전 테스트를 skip으로 PASS 처리하지 않는다. 디자인 결정서의 첫 낮 비용 예시 및 실제 수급이 표준 빌드 준비에 충분한지도 실측한다.
